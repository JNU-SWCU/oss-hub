GitHub 활동 수집·공개 범위

정책 버전: 2026-08-11

수집 범위와 목적

JNU-SWCU Org 저장소(가시성 무관)와 학생 GitHub 계정의 공개(public) 저장소 활동에서 저장소 식별자·가시성, 활동 시각·종류와 저장소 단위 최소 집계값을 프로그램 운영, 커뮤니티 활성화 지표 산출과 공개 랭킹 표기에 사용합니다. 개인 계정의 비공개 저장소는 이 정책의 수집 대상이 아닙니다.

수집하지 않는 정보

raw payload, 소스 코드, diff, commit message, author email, pull request 제목·본문, release 본문, 사용자 프로필은 저장하지 않습니다.

공개 범위

저장소 자체(코드·이슈·저장소 이름)의 공개는 이 정책과 별개입니다. private 저장소는 Platform ADMIN/STAFF와 해당 팀 구성원으로 접근을 제한하며, 공개 전환은 정해진 시점 이후 권한 있는 운영자의 명시적 동작으로만 수행하고 자동 공개하지 않습니다.

공개 랭킹 표기

공개 랭킹의 집계 숫자는 저장소를 공개하는 것과 별개입니다 — JNU-SWCU Org 저장소의 활동을 가시성과 무관하게 합산하며, 이 합산에는 위 「공개 범위」에 따라 여전히 비공개로 유지되는 저장소의 활동도 포함됩니다. 가입한 시점부터 활동 유무와 무관하게 GitHub 닉네임이 공개 랭킹에 표기되며, 기여가 없으면 0으로 표기됩니다. 공개 랭킹에 노출되는 항목은 GitHub 닉네임과 commit·PR·release 합산 수치뿐이며, 실명·저장소 이름·활동 시각·소속은 노출하지 않습니다.
