수집 항목과 목적

GitHub 계정 식별자·로그인명·이름·프로필 이미지, 사용자가 입력한 프로필·연락 정보, 역할과 동의 기록을 계정 식별·접근 제어·프로그램 운영에 사용합니다.

공개 랭킹 게시

가입한 시점부터 활동 유무와 무관하게 GitHub 닉네임이 공개 랭킹에 표시됩니다. 기여가 없으면 0으로 표시합니다. 비로그인 방문자와 학생 등 일반 회원에게 실명과 학과는 표시하지 않으며, 활성 상태의 교직원(STAFF)과 운영자(ADMIN)는 운영을 위해 실명과 학과도 볼 수 있습니다. 학번과 연락처는 랭킹에 표시하지 않습니다. 집계 숫자의 범위와 노출 항목은 GitHub 활동 수집·공개 범위(정책 버전 2026-10-19) 문서를 따릅니다.

보유와 삭제

회원정보와 개인 연결값은 회원 자격과 서비스 운영에 필요한 동안 보유합니다. 탈퇴나 연결 해제 시 개인 프로필과 개인 단위 공개 연결은 삭제 또는 비식별화하고 이후 노출을 중단합니다.

Org 자산과의 분리

개인정보 처리는 Org 저장소, Git 이력, 저장소 식별자와 저장소 단위 누적 지표를 자동으로 삭제하지 않습니다. 예외적인 정정·삭제는 플랫폼 운영 절차로 처리합니다.
