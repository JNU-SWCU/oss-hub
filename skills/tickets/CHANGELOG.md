# Changelog

- 2026-08-26 — v1.0.0: OSS Hub QA intake needed one reusable contract → added Notion deduplication, migration, verification, deadlines, and public GitHub handoff.
- 2026-08-26 — v1.1.0: UX tickets became implementation-first and ignored the operator-edited reference style → added a human-readable UX body, safe block replacement, and persisted-image verification. Provenance: 2026-08-26 operator correction during the OSS Hub UX QA ticket 2.1-2.5 rewrite conversation.
- 2026-08-26 — v1.2.0: UX reference research kept expanding or preserved rejected examples after the useful pattern was clear → added real-screen candidate review, familiar-pattern fallback, aspect-scoped approval recipes, and a stop-after-approval check. Provenance: 2026-08-26 operator-supplied OSS Hub QA reference-review conversation.
- 2026-08-27 — v1.3.0: 티켓이 frontend·backend·infra 중 무엇인지 선언하지 않아 증거 요구가 매번 재협상됐고, 화면 캡처는 어느 요소인지 모호했으며 참고 UI는 링크만 남았다 → 영역 선언과 영역별 최소 증거, selector 기준 요소 캡처, 캡처를 동반한 참고 UI, [UX 레퍼런스 카탈로그](references/ux-reference-catalog.md)를 추가했다. Provenance: 2026-08-27 운영자 대화에서 받은 daker.ai 정보 밀도 비교 — [daker.ai 공개 프로그램](https://daker.ai/public/hackathons).
- 2026-08-27 — v1.4.0: 티켓 본문이 곧장 `## 문제`로 시작해 읽는 사람에게 건네는 말이 없었고, 캡처·코드 앵커·중복 조회를 한 줄로 순서대로 돌려 대기 시간이 쌓였다 → 2~3줄 여는 말을 본문 계약에 넣고, 세 갈래 증거 수집을 동시 subagent lane으로 규정한 [증거 수집 파이프라인](references/evidence-pipeline.md)과 캡처·앵커·발행 전 팩트 체크를 맡는 agent 세 개를 추가했다. Provenance: 2026-08-27 운영자 대화 — 노션 말투 요청과 dom tree 탐색 subagent 분담 제안.
- 2026-08-28 — v2.0.0: QA 티켓 작성과 티켓 수행이 서로 다른 스킬에 있어 같은 계약이 두 문서에서 갈렸고, Notion 행과 GitHub Issue가 서로를 가리키지 않아 같은 문제로 두 번째 Issue가 만들어졌으며, 발행 권한이 두 사람으로 묶여 문제를 관찰한 사람이 티켓을 올리지 못했다 → `manage-qa-tickets`와 `tickets`를 `skills/tickets/` 하나로 합쳐 작성·발행·수행 3단계를 한 계약 아래 두고, [발행 계약](references/github-publication.md)에 Notion→Issue 본문 재작성·OSS Hub 자체 화면 캡처 반입 기준·`GitHub Issue` 속성 되돌려 연결·배정된 행 backfill을 규정했으며, [수행 워크플로](references/execution-workflow.md)를 참조로 재배치하고 발행 권한을 저널 파일을 가진 팀원 전체로 열었다. Provenance: 2026-08-28 운영자 요청 — 두 스킬 통합, Notion 행의 GitHub Issue 배포와 URL 연결, 팀 전체 발행 허용.
