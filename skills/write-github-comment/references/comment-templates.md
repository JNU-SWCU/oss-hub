# 코멘트 템플릿

네 템플릿이다. `<…>`는 빈칸이고, 괄호로 조건을 적은 줄은 해당하지 않으면 지운다.
어느 템플릿을 쓸지는 [SKILL.md](../SKILL.md#어느-코멘트인지-먼저-정한다)의 표를 먼저 본다.

## 지적 (리뷰어 → 작성자)

```markdown
**<번호>. <무엇이 어디서 — 한 줄>** ([`<경로:줄>`](<blob 링크>))

<왜 문제인가 — 사용자 비용 한 문장. UX면 AP-<n> 이름>

<img width="<w>" alt="<이 캡처가 보여 주는 것 한 문장>" src="<release asset URL>">
<sub>`<selector>` · `<URL 경로>` · <viewport> · <HEAD sha 또는 배포></sub>

→ 제안: <구체적인 변경 — 무엇을 무엇으로>
→ 판단 필요하면: <질문 한 줄>  (없으면 이 줄 삭제)
```

- 캡처는 frontend 지적에만 붙인다. backend 지적은 `경로:줄`과 코드 인용이 캡처를 대신한다.
- 지적이 backend 흐름(분기·상태 전이·호출 순서)을 다루면 캡처 자리를 상위 흐름 다이어그램으로 대신한다 — 진입 → 분기 → 결과 중심의 mermaid(우선) 또는 DOT, 8노드 이하. 형식은 [`backend-diagram.md`](../../submit-pr-evidence/references/backend-diagram.md)가 원본이다.
- 마지막에 「블로커 아님」 또는 「이건 블로커」를 한 단어로 남긴다 — 작성자가 우선순위를 스스로 추론하지 않게 한다.

## 답글 (작성자 → 리뷰어)

```markdown
<번호>. 고쳤어 — <어떻게, 한 줄> (<commit 7자>)
<번호>. 안 고쳤어 — <이유 한 줄>
<번호>. 판단 부탁 — <선택지 A / B와 각각의 비용 한 줄>

<After 요소 캡처가 있으면 여기 — 지적 템플릿과 같은 img+sub 형식>

초록불이 감추는 것: <재실행으로 통과한 검사 / 로컬 E2E 돌렸음·안 돌렸음 / 보류 항목>  (없으면 이 줄 삭제)
다음: <리뷰어가 할 행동 — 다시 봐줘 / 결정해줘 / 머지해도 돼>
```

- 리뷰어가 매긴 번호를 그대로 받는다 — 새로 번호를 매기면 어느 지적의 답인지 리뷰어가 다시 세야 한다.
- 위 말투 표기(반말)는 예시일 뿐이다 — 실제로는 작성자 자신의 말투를 따른다.
- 「초록불이 감추는 것」과 「본문 `## 검증`」의 역할 구분은 이 스킬의 [`### 초록불이 말해 주는 것은 쓰지 않고, 초록불이 감추는 것을 쓴다`](../SKILL.md#초록불이-말해-주는-것은-쓰지-않고-초록불이-감추는-것을-쓴다)가 원본이다.

## UX 제안 (누구든 → owner)

```markdown
<img width="<w>" alt="<지금 이 컴포넌트가 보여 주는 것>" src="<release asset URL>">
<sub>`<selector>` · `<URL 경로>` · <viewport> · <sha/배포></sub>

지금: <이 컴포넌트가 지금 하는 말 / 하는 일 — 한두 줄>
제안: <대신 이렇게 — 문구·컨트롤·상태를 구체적으로>
왜: <AP-<n> 또는 사용자 비용 한 문장>
경계: <이 PR 안 / 티켓으로 — 하나만>

결정 부탁: <owner가 답할 질문 하나>
```

- 현재 캡처 없이는 올리지 않는다. 캡처를 못 만들면 코멘트를 올리는 대신 캡처를 못 만든 이유를 사용자에게 보고하고 멈춘다.
- 대안 스케치가 있으면 두 번째 이미지로 붙이고 alt에 「제안 스케치」를 넣어 현재 캡처(증거)와 구분한다.
- 제안이 화면이 아니라 backend 흐름을 바꾸자는 것이면 캡처 자리를 상위 흐름 다이어그램으로 대신한다 — 진입 → 분기 → 결과 중심의 mermaid(우선) 또는 DOT, 8노드 이하. 형식은 [`backend-diagram.md`](../../submit-pr-evidence/references/backend-diagram.md)가 원본이다.

## 진행 (Issue)

```markdown
PR: #<번호> (<상태 — 열림 / 리뷰 중 / 머지됨>)
남은 것: <한 줄 또는 불릿>
막힌 것: <무엇이, 누구 결정이 필요한지>  (없으면 삭제)
```

- Issue 자체의 본문(계약)은 이 템플릿의 대상이 아니다 — `manage-qa-tickets`가 다룬다.
