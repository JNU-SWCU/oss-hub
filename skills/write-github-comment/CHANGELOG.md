# Changelog

- 2026-09-09 — v1.1.0: 결론·다음 행동·블로킹 여부를 먼저 보여 주고 유지 의견을 짧게 쓴다. 기존 구현 재사용을 먼저 검토하며 승인 조건과 안전 경계를 보존한다. 긴 근거는 아래로 옮기고 반복 설명·흐름 불변 도식을 줄였다.

Provenance: 2026-09-08 team-lead — 「pr과 issue에 코멘트를 달 때도 스킬이 있으면 좋겠어 … 실제 컴포넌트가 이런데 이런게 낫지 않는가 이야기하도록 … ci, test 몇개 통과했다고 하는데 이거는 말안해도 알고」.
