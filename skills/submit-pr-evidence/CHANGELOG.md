# Changelog

- 2026-09-04 — v1.4.0: 게이트는 옳았는데 통과할 방법이 적혀 있지 않아, QA 회차 하나에서 같은 자리에 반복해서 걸렸다 → 네 가지를 인코딩했다. (1) **캡처 첨부가 사람 손을 요구한다는 서술을 정정했다** — `gh release upload`로 **이미 발행된** release에 파일을 더하는 것은 배포 트리거(`release: types: [published]`)를 쏘지 않으므로 안전하고, PM이 PR #1186에서 실제로 쓰던 방법이다. `gh release create`만 금지로 남긴다. (2) [`references/evidence-harness.md`](references/evidence-harness.md)를 새로 두어 local-review 하네스로 Before/After를 같은 조건에서 얻는 법, 요소 캡처가 빈 화면으로 나오는 세 원인, 같은 이름의 버튼이 여럿일 때 눌리는 것을 고르는 법, 빈 상태 세 갈래를 **실제로 서로 다르게** 만들어 확인하는 법, 그리고 PR 본문을 따옴표 heredoc으로 만들어야 하는 이유(따옴표 없는 heredoc이 백틱을 실행해 `deletionProtected`가 통째로 사라진 채 발행된 적이 있다)를 적었다. (3) **찍을 수 없는 상태는 fixture를 채워서 찍는다**를 게이트의 일부로 명시했다 — 아무도 눈으로 확인할 수 없는 화면은 조용히 낡고, 실제로 fixture를 채우다 「값이 없으면 조용히 기본값으로 떨어지는」 결함이 드러나 캡처 게이트가 아니었으면 통과했을 변경을 잡았다. (4) 절차 7단계에 **「초록불이 돌았다는 뜻은 아니다」**를 넣었다 — 없는 워크스페이스 이름으로 필터하면 pnpm이 아무것도 실행하지 않고 exit 0을 내고, 배열 플래그 뒤 경로가 ignore 값으로 먹혀 고친 파일이 조용히 제외되며, rebase 충돌을 풀다 옛 코드가 새 코드보다 먼저 반환하는 상태를 lint·typecheck가 둘 다 통과시키고 전체 테스트만 잡았다. 그래서 검증 보고에 실행된 suite·test 개수를 적게 했다. 더해서 push를 막는 로컬 관문 두 개(`docs/handoff/team-state/` 저널 항목, 저장소 전체 prettier)를 절로 분리하며 저널과 PR 본문의 독자가 다르다는 것을 밝혔고, 인터뷰가 **티켓의 방향 자체를 뒤집는 경우** 티켓 본문의 `할 일`도 다시 쓰고 앞선 방향의 코드를 걷어내도록 했으며, 안티패턴 자동 점검에 가시성 필터를 넣어 반응형 중복 내비게이션 거짓 양성을 없애고 구조적 반복을 위반으로 적지 않도록 판정 지침을 더했다. Provenance: PM이 PR #1190을 읽고 「이번 PR 만드시면서 더 고려하신 부분이 있다면 저희 PR skill에 반영 주실 수 있을까요」라고 요청 — QA 회차 #1081의 PR 8건을 만들며 실제로 걸린 자리를 스킬로 옮겼다.

- 2026-09-03 — v1.3.0: PR 본문이 증거를 갖춰도 사람이 읽을 수 없었다 — PR #1171은 Before 캡처 0장·구현 언어 요약·`\title` 렌더 깨짐으로 도착했는데 required CI는 전부 통과했고, 배포 화면 `/programs/<id>/status`는 `전체 미제출 5팀`을 통계와 필터에 글자 그대로 두 번 그리고 있었다 → Nielsen 10 usability heuristics에 앵커링한 [`references/ux-antipatterns.md`](references/ux-antipatterns.md) 여덟 항목(자동 점검 4 + 사람 판단 4)을 절차 8단계 게이트로 넣고, 캡처 게이트에서 `N/A`를 없애 화면을 건드린 모든 변경에 Before/After 표·전체 화면 2장·`jnu-oss-hub.com` 확인 링크를 요구하며, PR 본문 순서를 사람이 읽는 것 우선으로 고정해 `## 고친 파일`을 맨 아래로 내리고 섹션 번호를 없앴다. 본문을 렌더된 상태로 다시 읽는 원칙과 완료 체크리스트 항목도 함께 추가했다. Provenance: PM이 PR #1171과 배포 화면을 읽고 「학생이 첫 QA, 나는 마지막 product gate」로 책임을 옮겨 달라고 요청 — 안티패턴을 스킬에 인코딩해 아무도 몰라도 지켜지게 할 것.
