# Changelog

- 2026-09-03 — v1.3.0: PR 본문이 증거를 갖춰도 사람이 읽을 수 없었다 — PR #1171은 Before 캡처 0장·구현 언어 요약·`\title` 렌더 깨짐으로 도착했는데 required CI는 전부 통과했고, 배포 화면 `/programs/<id>/status`는 `전체 미제출 5팀`을 통계와 필터에 글자 그대로 두 번 그리고 있었다 → Nielsen 10 usability heuristics에 앵커링한 [`references/ux-antipatterns.md`](references/ux-antipatterns.md) 여덟 항목(자동 점검 4 + 사람 판단 4)을 절차 8단계 게이트로 넣고, 캡처 게이트에서 `N/A`를 없애 화면을 건드린 모든 변경에 Before/After 표·전체 화면 2장·`jnu-oss-hub.com` 확인 링크를 요구하며, PR 본문 순서를 사람이 읽는 것 우선으로 고정해 `## 고친 파일`을 맨 아래로 내리고 섹션 번호를 없앴다. 본문을 렌더된 상태로 다시 읽는 원칙과 완료 체크리스트 항목도 함께 추가했다. Provenance: PM이 PR #1171과 배포 화면을 읽고 「학생이 첫 QA, 나는 마지막 product gate」로 책임을 옮겨 달라고 요청 — 안티패턴을 스킬에 인코딩해 아무도 몰라도 지켜지게 할 것.

- 2026-09-02 — v1.1.0: PR 본문이 증거는 갖췄어도 "무엇을 고쳤다" 식 구현 언어로 쓰여 리뷰어가 읽기 힘들었다 → `## 증거 게이트`와 `## PR을 연다` 사이에 `## PR 본문 작성 원칙` 절을 추가해 페르소나 언어 요약, 사람이 확인한 행동 중심 검증 서술, 로컬 환경 잡음 배제(단 실행 못 한 검증은 예외), 중첩 불릿·클릭 가능한 파일 링크·정합된 섹션 번호, 미첨부 placeholder 금지를 규정하고 완료 체크리스트에 두 항목을 추가했다.
