테스트가 증명한 실패 경로:
misleading_success_output: 빈 파일, 결과 없는 문장, 비정수 출력, 두 줄 출력, 앞 문장 오류, 쓰기 시도, RAISE EXCEPTION이 세 점검 중 가운데 있어도 exit 1이고 OK 줄이 없다.
hung_commands: 느린 쿼리, 멈춘 psql, 멈춘 docker 클라이언트, 멈춘 pg_dump, 멈춘 객체 복사, 멈춘 이전 이미지 확인이 제한 시간 안에 exit 1로 끝난다. 멈춘 psql은 컨테이너에 남지 않는다.
stale_state: 기존 백업을 덮어쓰지 않는다. 영수증과 다른 덤프나 객체는 재검증에서 실패한다. 원장 머리가 다른 덤프는 첫 단계 전에 멈춘다. 남은 리허설 DB가 있으면 시작하지 않는다. 실패와 SIGTERM 중단 뒤 리허설 DB와 훅 프로세스가 남지 않는다.
비밀 노출: 모든 테스트 실행의 stdout과 stderr에서 DB 비밀번호와 저장소 키 표지값이 나오지 않는다. 훅이 키를 출력해도 로그에 남지 않는다. SQL 오류의 행 값도 남지 않는다.
