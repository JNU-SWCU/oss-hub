기준: 2366e1833
운영 접근, 운영 쓰기, 머지, 배포는 수행하지 않았다.
guide의 화면·문구는 바뀌지 않는다. 개발 환경설정 안내만 README에서 갱신했다.

배포 순서
1. 이 준비 릴리스의 frontend와 backend를 먼저 배포한다.
2. 이 릴리스가 실행 중임을 확인한 다음 별도 릴리스에서 컬럼 삭제와 API 상태값 전환을 한다.
두 릴리스를 한 번에 배포하면 계약 15(c)를 위반한다.

첫 마이그레이션은 옛 컬럼을 삭제하지 않는다. 새 Prisma 모델은 옛 컬럼을 SELECT/INSERT하지 않으며,
기존 DB id/joinCodeDigest 기본값은 마이그레이션-앱 교체 구간의 새 INSERT를 지원한다.
TeamMember의 물리 PK는 아직 id이고, 새 클라이언트의 복합키 쿼리는 기존 UNIQUE를 사용한다.
Program과 Milestone의 sentinel 기본값 및 쓰기 보정은 제거한다.
Milestone -> Program 기간 검증은 유지한다. 역방향 트리거는 추가하지 않는다.
기존 종료일 미정 값의 조회 계약은 보존한다. 신규 종료일 입력은 기존 서비스가 검증한다.

사전 점검
한 트랜잭션 안에서 SubmissionFile 및 MilestoneDocumentTemplateFile 저장 키 중복,
시작일 sentinel, 프로그램 범위 밖 마일스톤, TeamMember incoming FK를 확인하고 이상 시 중단한다.
실제 운영 데이터의 사전 점검·백업은 배포 담당자의 후속 실행 사항이며 여기서는 수행하지 않았다.
추정 날짜 백필과 중복 파일 자동 삭제는 하지 않는다.

pnpm dev, 실제 로그인, 운영 API는 사용하지 않았다.

실패 탐침
stale_state: 모든 DB 실행은 새 project와 빈 DB에서 migrate deploy했다.

bash apps/backend/test/run-integration.test.sh: EXIT=0.
flaky_tests: 새 테스트는 고정 시각과 완료된 DB 작업을 사용하고 sleep이 없다.
같은 초대·탈퇴 계약을 별도 빈 DB 실행에서 반복 확인했다.

검토
원시 삭제 지문도 TeamMember.id 대신 (teamId, userId)를 사용한다.
EXPIRED와 준비팀 invitedAt, 프로비저닝 상태 머신은 변경하지 않았다.
삭제한 테스트는 제거된 가입 코드 생성·비밀값·충돌 재시도 기능만 검사하던 테스트다.
동작 중인 준비팀·지원·권한·삭제 테스트는 유지했다.
가입 코드용 env를 실제 secret store에서 삭제하지 않았다. 기존 배포 롤백은 스냅샷된 이전 compose를 사용한다.

정리
각 통합 실행의 EXIT trap이 해당 컨테이너·볼륨·네트워크를 제거했다.
브라우저 e2e가 자체 Next 서버와 Chrome context를 종료했다.
원본 로그·이미지의 로컬 경로와 합성 DB 접속 문자열은 공개 요약에 포함하지 않았다.
