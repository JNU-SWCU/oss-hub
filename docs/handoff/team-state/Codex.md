## 2026-09-09 — 업로드 상한을 서버 응답으로 통일

- 상태: review
- Issue: #1210 — 업로드 상한의 화면 사본 제거
- PR: (이 PR)
- blocker: 업로드 정책 응답 API를 먼저 배포해야 한다.
- 변경: 최초 제출·다시 제출·교직원 프로그램 작성의 상한 표시와 검증이 서버 응답을 사용한다.
  제한을 넘는 파일을 고르면 제출 버튼을 누르기 전에 오류를 표시하고, 유효한 파일로 바꾸거나 선택을 취소하면 오류를 지운다.
  기존 교직원 양식 입력의 오류와 입력 컨트롤을 접근성 속성으로 연결했다.
- 범위: 최신 main의 학생 PDF/HWP/ZIP 정책과 교직원 양식 형식 목록을 유지했다.
  반려 학생 버튼 잠금과 다시 게시 문구는 변경하지 않았다.
- 검증: main 8510328d 기반의 동일한 frontend 소스에서 352개 파일·3,559개 테스트 통과, typecheck 통과, lint 오류 0개·기존 경고 5개, 변경 파일 포맷 검사 통과.
- 인터뷰 반영: 화면 종류와 관계없이 파일 선택 시점에 초과 여부를 알리고 서버 한도와 같은 안내를 사용하도록 한 요청을 반영했다.
