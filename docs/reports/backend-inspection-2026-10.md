## Route usage

`node scripts/api-route-usage.mjs --json`은 TypeScript compiler API로 컨트롤러 데코레이터와 프론트엔드 호출 표현식을 파싱한다. 스냅샷이 아직 없는 상태에서 컨트롤러 52개, 초기 핸들러 **156개 = used 137개 + unusedCandidates 19개**를 재생성했다. todo 19 이후에는 **144개 = used 137개 + 정당한 유지 후보 7개**다. `--placement`는 모든 라우트에 프론트엔드 파일·행을 붙인다. 테스트·fixture·support 파일은 자동 사용 집계에서 제외한다.

대상은 `apiClient`, `apiFileClient`, `apiPath`(링크/다운로드), `serverApi*`, `landingJson`, `fetch`, `fetchPublicJson`과 경로를 첫 인자로 전달하는 로컬 래퍼다. 로컬 경로 빌더, 조건부 prefix, literal union, query suffix를 해석하고 `${...}`는 `:param`으로 바꾼다. HTTP method와 경로 segment를 함께 비교하고 정적 라우트를 파라미터 라우트보다 우선한다.

이는 호출 가능성 분석이지 실행 횟수나 도달 가능성 증명이 아니다. 파일 간 import된 경로 빌더, 서버 응답의 URL, 임의 함수의 인자 전파는 완전히 추적하지 않는다. 따라서 아래 후보를 곧바로 삭제 목록으로 쓰면 안 된다. 파싱 불가능한 TS는 stderr 경고 후 건너뛰므로 경고와 총 핸들러 수도 함께 확인해야 한다.

### Production findMany without top-level take

범위는 `apps/backend/src/**/*.ts`의 실행 코드다. spec/test/fixture/support, 타입 선언, nested relation select를 제외하고 CallExpression 첫 인자의 **최상위** take만 검사했다. todo 19에서 전용 invariant 조회 2개를 제거한 뒤 남은 103개를 아래에 분류했다: B 21개, U 82개. 초안의 70 calls/30 files는 테스트와 nested take 때문에 이 체크아웃의 값으로 사용할 수 없다.

**B (bounded)** 는 명시적 입력 ID 집합 또는 유일 키 조합으로 행수가 제한되는 보조 조회다. 상수 상한이나 안전성 증명이 아니며, 입력 집합에 상한이 없으면 원본 조회의 위험을 상속한다. **U (unbounded)** 는 query-level 행수 상한이 없는 조회다. 사용자/program/기간 필터만으로 건수가 보장되지는 않는다. U는 즉시 버그라는 뜻이 아니다. export와 정합성 검사에도 메모리/실행 시간 예산이 필요하다는 분류다. nested relation의 증폭은 별도 측정한다.
