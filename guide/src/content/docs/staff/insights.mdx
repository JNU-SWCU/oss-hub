`학생 활성`은 전공별 GitHub 활동과 프로그램 참여를 비교하는 화면입니다. 왼쪽 `교직원` 메뉴의 ① `학생 활성`에서 엽니다.

<Shot src="staff/insights-full.webp" alt="학생 활성 화면 전체. ①이 왼쪽 메뉴의 학생 활성을 가리킵니다. 위에 가입 학생, 활동 학생, 프로그램 참여자 카드가 있고 아래에 전공별 활성 지표와 프로그램별 참여 차트가 있습니다." caption="① 학생 활성" />

## 기간과 비교 기준 바꾸기

<Steps>
1. ① `기간`에서 연도를 고릅니다.
2. ② `비교 관점`에서 `전공·비전공` 또는 `학과`를 고릅니다.
3. 아래 카드와 차트가 바뀝니다.
</Steps>
<Shot src="staff/insights-filters.webp" alt="기간과 비교 관점 선택. ①이 기간 선택, ②가 비교 관점의 학과 선택을 가리킵니다." caption="① 기간 ② 비교 관점" />

## 숫자 읽기

- `가입 학생`: 가입한 학생 수입니다. `학과 미등록 N명`은 학과를 아직 입력하지 않은 학생입니다.
- `활동 학생`: 커밋, PR, 이슈, 저장소, Star 수를 더한 랭킹 합계가 1 이상인 학생입니다.
- `프로그램 참여자`: 현재 승인된 신청자와 팀원을 프로그램별로 중복 없이 센 수입니다.
- `활성 — 랭킹 지표`, `학과별 활성`, `참여 — 프로그램별`: 위 수를 지표별, 학과별, 프로그램별로 나눈 차트입니다.
- 분모가 0이면 비율 대신 `x/0 (계산 불가)`로 나옵니다.

<Success>
고른 기간과 비교 관점에 맞는 카드와 차트가 보입니다.
</Success>

<Recover title="차트가 비어 있을 때">
- `학과별 학생이 없습니다`, `승인된 참여가 없습니다`: 고른 기간에 대상이 없습니다. 정상입니다. 기간을 바꿔 보세요.
- `학생 활성을 불러오지 못했습니다`: 화면을 새로 고칩니다. 반복되면 관리자에게 [시스템 상태](/oss-hub/admin/system-status/) 확인을 요청하세요.
</Recover>

관리자 화면의 같은 종류 통계는 [학생 활성 보기](/oss-hub/admin/insights/)에서 설명합니다.
