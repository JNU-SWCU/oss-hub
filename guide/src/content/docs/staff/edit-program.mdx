`프로그램 편집` 화면은 만든 프로그램을 고치는 곳입니다. 운영 대시보드에서 프로그램 이름을 누르면 열립니다. 프로그램 정보, 마일스톤, 제출 항목은 따로 저장됩니다. 한 영역을 저장해도 다른 영역은 저장되지 않으니 영역마다 저장 버튼을 누르세요.

제출 항목은 [프로그램 만들기](/oss-hub/staff/create-program/) 단계에서는 만들 수 없고 여기서 추가합니다. 학생은 이 항목에 맞춰 서류를 냅니다.

## 신청·운영 일정 바꾸기

<Steps>
1. `신청 기간` 또는 `운영 기간` 카드의 ① 연필 아이콘(`신청 기간 수정`)을 누릅니다.
2. 날짜와 시각을 바꾸고 적용합니다.
3. 위쪽 정보 영역의 ② `프로그램 정보 저장`을 누릅니다.
</Steps>
<Shot src="staff/edit-schedule.webp" alt="프로그램 편집 화면의 일정 영역. 신청 기간과 운영 기간 카드가 있고 ①이 신청 기간 카드의 연필 아이콘, ②가 프로그램 정보 저장 버튼을 가리킵니다." caption="① 신청 기간 수정 ② 프로그램 정보 저장" />

날짜를 적용하기만 해서는 저장되지 않습니다. `날짜를 적용한 뒤 프로그램 정보 저장을 눌러야 저장됩니다.`

참여 인원을 고칠 때, 개인으로만 신청받으려면 최소 인원과 최대 인원을 모두 1명으로 정합니다.

<Success>
`저장되었습니다.`가 잠깐 나타납니다.
</Success>

## 마일스톤 추가하고 고치기

<Steps>
1. `마일스톤` 영역에서 ① `추가`를 누릅니다. 이름과 기간을 정하는 창이 열립니다.
2. 이미 있는 마일스톤은 ② 연필 아이콘(`{이름} 수정`)을 눌러 엽니다.
3. 이름, 기간, `운영자 공지`를 고칩니다.
4. 창 아래 `마일스톤 저장`을 누릅니다.
</Steps>
<Shot src="staff/edit-milestones.webp" alt="프로그램 편집 화면의 마일스톤 영역. ①이 추가 버튼, ②가 1차 기획서 제출 카드의 연필 아이콘을 가리킵니다. 카드에 기간과 제출 항목 요약이 있습니다." caption="① 마일스톤 추가 ② 마일스톤 수정" />

마일스톤에는 제출 항목이 하나 이상 있어야 하므로, 여기서 새로 만든 마일스톤에는 항목 하나가 자동으로 들어갑니다. 항목을 모두 지우려 하면 `마일스톤에는 제출 항목이 하나 이상 필요합니다. 새 항목을 만든 뒤 기존 항목을 삭제해 주세요.`가 나옵니다. 새 항목을 먼저 만드세요.

## 제출 항목 만들고 고치기

제출 항목은 마일스톤 수정 창의 `제출 항목`에서 만들고 고칩니다. 마일스톤 하나에 최대 20개, 프로그램 전체로는 최대 100개입니다.

<Steps>
1. ① `제출 항목 추가`를 누르면 빈 항목 카드가 생깁니다.
2. 연필 아이콘(`제출물 이름 수정`)을 눌러 이름 칸을 열고 이름을 입력한 뒤, 체크 아이콘(`제출물 이름 적용`)으로 확정합니다. 이름은 200자까지입니다.
3. ① `필수 제출` 체크로 필수 여부를 정합니다. 체크를 풀면 `선택 제출`로 바뀝니다.
4. 학생에게 양식을 줘야 하면 ② 새로고침 모양 아이콘(`첨부파일 업로드`)으로 양식 파일을 올립니다. 이미 올렸다면 같은 아이콘이 `첨부파일 재업로드`가 됩니다. 허용 형식은 PDF, HWP, JPG, PNG, ZIP이고 최대 5 MB입니다.
5. 항목 왼쪽 손잡이를 끌어 순서를 바꿉니다. 휴지통 아이콘으로 항목을 지웁니다. 지운 항목은 저장하기 전까지 `저장 시 삭제: {이름}`으로 표시됩니다.
6. ② `마일스톤 저장`을 누릅니다.
</Steps>
<Shot src="staff/milestone-edit.webp" alt="마일스톤 수정 창. 제출 항목 카드 두 개가 있고 ①이 제출 항목 추가 버튼, ②가 마일스톤 저장 버튼을 가리킵니다." caption="① 제출 항목 추가 ② 마일스톤 저장" />
<Shot src="staff/item-editor.webp" alt="제출 항목 카드. ①이 첫 항목의 필수 제출 체크, ②가 첨부파일 업로드 아이콘을 가리킵니다. 아래의 새 항목 카드에는 이름을 입력해 달라는 빨간 문구가 있습니다." caption="① 필수 제출 ② 첨부파일 업로드 (아래 새 항목은 이름이 비어 있는 상태)" />

새 항목을 추가하면 이름을 쓰기 전에도 `제출 항목 이름을 입력해 주세요.`가 바로 나옵니다. 이름을 입력하면 사라집니다.

<Success>
마일스톤 카드에 `프로젝트 기획서 · 필수`처럼 항목 이름과 필수 여부가 나옵니다. 학생의 제출 화면에도 같은 항목이 나타납니다.
</Success>

## 마일스톤 삭제하기

마일스톤 카드의 휴지통 아이콘을 누르면 `마일스톤을 되돌릴 수 없이 삭제할까요?`가 나오고, `삭제 확정`을 눌러야 지워집니다. 되돌릴 수 없으니 확정 전에 이름을 다시 확인하세요.

## 프로그램 삭제하기

화면 맨 아래 `위험 영역`의 ① `프로그램 삭제`는 프로그램과 거기 연결된 데이터를 지우며, 지운 뒤에는 되돌릴 수 없습니다. 누르면 `프로그램을 삭제할까요?`로 한 번 더 묻습니다. 감사 기록과 사용자 계정은 남습니다. 삭제 전에 신청과 제출 현황을 확인하세요.

<Shot src="staff/edit-danger.webp" alt="프로그램 편집 화면 맨 아래의 위험 영역. ①이 프로그램 삭제 버튼을 가리킵니다." caption="① 프로그램 삭제" />

삭제 방법은 [프로그램 삭제하기](/oss-hub/admin/delete-program/)에 있습니다. 지금은 OSS Hub가 프로그램 담당자를 구분하지 않아, 교직원이면 다른 교직원의 프로그램도 고치거나 지울 수 있습니다. 이렇게 해도 되는지 운영 정책이 정해지지 않았으니, 손대기 전에 그 프로그램을 맡은 교직원과 먼저 상의하세요. <Verified status="policy" />

<Recover title="저장이 되지 않을 때">
- `제출물이 있는 마일스톤은 삭제할 수 없습니다.` 학생이 이미 낸 서류가 있습니다. 지울 수 없으니 이름과 기간만 고치세요.
- 저장소 자동 발급이 켜진 프로그램에서는 마지막 마일스톤을 지울 수 없습니다. 발급을 끄거나 다른 마일스톤을 먼저 만드세요.
- `제출 항목 이름을 입력해 주세요.` 비어 있는 항목에 이름을 쓰거나 항목을 지웁니다. 파일 양식을 올리는 항목이면 `파일 재선택 필요`가 나올 때 파일을 다시 올립니다.
- 마일스톤 기간이 저장되지 않으면 시작이 운영 시작일과 같거나 그 뒤인지, 끝이 운영 종료를 넘지 않는지 확인하세요.
</Recover>
