프로그램은 5단계 화면에서 만듭니다. 단계는 `기본 정보`, `신청/운영 일정`, `마일스톤`, `운영 설정`, `최종 검토` 순서입니다. 마지막에 `생성 확정`을 누르기 전에는 프로그램이 만들어지지 않습니다.

메뉴에서 `프로그램`을 열고, 프로그램 목록의 `프로그램 만들기`를 누릅니다. 만들고 난 뒤 고칠 수 있는 것은 [프로그램 고치기](/oss-hub/staff/edit-program/)에서 설명합니다.

작성 중에 다른 화면으로 나가려 하면 `작성 중인 내용이 있습니다. 나가면 복구 정보가 삭제됩니다.`가 나옵니다.

## 1단계. 기본 정보

<Steps>
1. `프로그램명`을 입력합니다.
2. 필요하면 `대표 이미지`를 올립니다. JPG와 PNG, 최대 5 MB입니다. 올린 이미지 위의 `교체`와 `삭제`로 바꾸거나 지웁니다.
3. ① `주관기관`, `교과/비교과`, `인원`을 채웁니다. `교과/비교과`는 둘 중 하나를 누릅니다. `인원`은 최소와 최대를 `-`와 `+`로 정하거나 숫자로 입력합니다. `주관기관`은 칩으로 입력하며 기본값은 `전남대학교 SW중심대학사업단`이고 지울 수 있습니다. 이름을 쓰고 Enter나 쉼표(`,`)를 누르면 칩이 추가되고, 칩의 `×`를 누르면 지워집니다. 쉼표로 이어 쓴 이름을 붙여 넣으면 한 번에 여러 칩이 생깁니다. 주관기관은 10개까지, 이름은 50자까지입니다. 인원은 1명에서 100명 사이입니다.
4. `소개/설명`을 씁니다. 별표(`*`)가 붙은 칸은 필수입니다.
5. ② `계속`을 누릅니다.
</Steps>
<Shot src="staff/create-step1.webp" alt="프로그램 만들기 1단계 화면. 프로그램명, 대표 이미지, 주관기관, 교과/비교과, 인원, 소개 입력칸이 있고 ①이 주관기관 칩 두 개, ②가 계속 버튼을 가리킵니다." caption="① 주관기관 ② 계속" />

이미 올린 공고가 있으면 오른쪽 위 `공고 불러오기`로 공고를 고릅니다. 공고에서 찾은 프로그램명, 소개/설명, 대표 이미지, 주관기관, 신청 기간, 운영 기간, 인원이 체크된 후보로 나옵니다. 지금 값과 비교해 반영할 항목만 남기고 적용합니다. 마일스톤과 제출 마감일은 불러오지 않으므로 3단계에서 직접 정합니다.

## 2단계. 신청/운영 일정

<Steps>
1. ① `신청 기간` 카드를 누르고, 달력에서 학생이 신청할 수 있는 시작일과 끝일을 차례로 누릅니다.
2. `운영 기간` 카드를 눌러 달력을 바꾼 뒤, 같은 방식으로 프로그램이 진행되는 시작일과 끝일을 누릅니다.
3. `계속`을 누릅니다.
</Steps>
<Shot src="staff/create-step2.webp" alt="프로그램 만들기 2단계 화면. 신청 기간과 운영 기간 카드가 있고 ①이 신청 기간 카드를 가리킵니다." caption="① 신청 기간" />

신청 마감일은 운영 종료일과 같거나 그보다 앞서야 합니다. 어긋나면 다음 단계로 넘어가지 않습니다.

## 3단계. 마일스톤

마일스톤은 학생이 서류를 내는 단계입니다. 1개에서 50개까지 만들 수 있습니다.

<Steps>
1. ① `마일스톤 추가`를 누릅니다.
2. 창에서 `기간`을 정합니다. 시작은 운영 시작일과 같거나 그 뒤여야 하고, 끝은 운영 종료일을 넘으면 안 됩니다.
3. `마일스톤 이름`을 쓰고, 학생에게 알릴 말이 있으면 `운영자 공지`에 씁니다. 참고 파일은 `첨부파일 추가`로 붙입니다(최대 5 MB).
4. `저장`을 누릅니다.
</Steps>
<Shot src="staff/create-step3.webp" alt="프로그램 만들기 3단계 화면. 마일스톤 카드에 제출 항목이 없습니다 안내가 있고 ①이 마일스톤 추가 버튼을 가리킵니다." caption="① 마일스톤 추가" />
<Shot src="staff/create-milestone-dialog.webp" alt="마일스톤 추가 창. 기간, 운영자 공지, 첨부파일 추가 칸이 있고 ①이 마일스톤 이름 입력칸, ②가 저장 버튼을 가리킵니다." caption="① 마일스톤 이름 ② 저장. 날짜 칸의 표기 순서는 브라우저 언어에 따라 다릅니다" />

이 단계에서는 제출 항목을 만들 수 없습니다. 카드에 `제출 항목이 없습니다. 수정에서 추가하세요.`가 나오는 것이 정상입니다. 프로그램을 만든 뒤 [제출 항목 추가하기](/oss-hub/staff/edit-program/)에서 채웁니다. 제출 항목이 없는 마일스톤은 학생에게 `제출 없음`으로 보입니다.

## 4단계. 운영 설정

<Steps>
1. ① `GitHub 저장소 발급`을 켤지 정합니다. 기본은 꺼짐입니다. 켜면 신청을 승인할 때 저장소가 자동으로 발급됩니다. 끄면 `신청 승인 시 저장소를 자동으로 발급하지 않습니다.`라고 나옵니다.
2. ② `제출 마감 알림`을 켤지 정합니다. 기본은 켜짐입니다. 끄면 `자동 알림을 사용하지 않습니다.`라고 나옵니다. 프로그램을 만든 뒤에는 편집 화면의 `운영 설정`에서 같은 설정을 바꿉니다. 프로그램 개요와 편집 화면에서 `메일 보내기`로 일반 메일을 쓰거나 `마감 알림 보내기`로 학생 알림과 교직원 요약을 보냅니다. 보내는 방법은 [지원자에게 메일 보내기](/oss-hub/staff/reminder-mail/)에 있습니다.
3. `계속`을 누릅니다.
</Steps>
<Shot src="staff/create-step4.webp" alt="프로그램 만들기 4단계 화면. ①이 켜진 GitHub 저장소 발급 체크 칸을 가리킵니다." caption="① 저장소 발급을 켠 모습" />
<Shot src="staff/create-step4-off.webp" alt="프로그램 만들기 4단계 화면. ①이 꺼진 GitHub 저장소 발급 체크 칸, ②가 제출 마감 알림 체크 칸을 가리킵니다." caption="① 저장소 발급(꺼짐) ② 제출 마감 알림" />

저장소 발급을 켜면 마일스톤이 하나 이상 있어야 하고, 프로그램을 만든 뒤에도 마지막 마일스톤은 지울 수 없습니다.

## 5단계. 최종 검토와 생성

<Steps>
1. `최종 검토`에서 입력한 내용을 읽습니다. 고칠 곳이 있으면 `이전`으로 돌아갑니다.
2. ② `프로그램 만들기`를 누릅니다.
3. `프로그램을 생성하시겠습니까?` 창에서 `생성 확정`을 누릅니다.
</Steps>
<Shot src="staff/create-step5.webp" alt="프로그램 만들기 최종 검토 화면. 인원과 일정 요약이 있고 ②가 프로그램 만들기 버튼을 가리킵니다." caption="② 프로그램 만들기. 인원과 일정을 확인한 뒤 누릅니다" />
<Shot src="staff/create-confirm-dialog.webp" alt="프로그램 생성 확인 창. 취소와 생성 확정 버튼이 있습니다." caption="`생성 확정`을 누르면 프로그램이 만들어집니다" />

<Success>
프로그램이 만들어지고 새 프로그램의 개요 화면이 열립니다. 나중에는 `운영 대시보드` 목록에서 이름으로 찾을 수 있습니다. 신청 기간이 시작되면 학생이 프로그램을 찾아 신청할 수 있습니다.
</Success>

<Recover title="만들어지지 않을 때">
- `프로그램 생성에 실패했습니다. 같은 내용으로 다시 시도해 주세요.` 입력한 내용은 그대로 있습니다. 다시 `생성 확정`을 누르기 전에 대시보드를 열어 같은 이름의 프로그램이 이미 생겼는지 보세요.
- `이전 요청으로 생성된 프로그램이 있을 수 있습니다…`: `기존 프로그램 확인`을 눌러 보고, 없을 때만 다시 만드세요. 중복 생성을 피하기 위해서입니다.
- 2단계에서 `시작일을 선택해 주세요.`가 나오면 `운영 기간` 카드를 눌러 운영 기간의 시작일과 끝일도 고르세요.
- 다음 단계로 넘어가지 않을 때: 별표(`*`) 칸이 비었거나, 신청 마감이 운영 종료보다 늦거나, 인원이 1~100을 벗어났는지 확인하세요.
</Recover>
