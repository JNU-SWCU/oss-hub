OSS Hub에는 따로 회원가입하는 곳이 없습니다. GitHub 계정으로 처음 로그인하면 가입 화면이 이어지고, 세 단계를 마치면 가입이 끝납니다. 먼저 GitHub 계정을 준비하세요.

## 로그인하기

<Steps>
1. 첫 화면 오른쪽 위 `로그인`을 누릅니다. 첫 화면의 `시작하기` 버튼을 눌러도 됩니다.
2. GitHub 로그인 화면에서 계정으로 로그인하고 권한을 허용합니다.
</Steps>

이미 로그인했지만 가입을 마치지 않았다면 `로그인` 대신 `가입 이어하기`가 보입니다. 그 버튼을 누르면 멈춘 단계부터 이어집니다.

<Shot src="student/signup-consent.webp" alt="가입 1단계 화면. 제목은 개인정보·활동 동의이고 동의 항목 세 개와 동의하고 계속 버튼이 있습니다." caption="로그인하면 처음 만나는 동의 화면" />

로그아웃한 뒤 오른쪽 위 `로그인`을 다시 누르면 GitHub 계정 선택 화면이 먼저 나옵니다. `Signed in as` 옆의 계정이 맞으면 `Continue`를 누르세요. 다른 계정으로 들어가려면 `Use a different account`를 누릅니다. 이미 가입한 계정은 가입 화면 없이 바로 OSS Hub로 돌아옵니다.

## 1단계. 동의

<Steps>
1. 동의 항목을 읽습니다. 항목 오른쪽 `전문 보기`에서 전문을 볼 수 있습니다.
2. 모든 항목에 체크합니다.
3. `동의하고 계속`을 누릅니다.
</Steps>

동의하지 않으면 다음 단계로 넘어갈 수 없어 서비스를 쓸 수 없습니다. 동의 정책이 바뀌면 이 화면이 다시 나옵니다.

## 2단계. 역할 고르기

`어떤 역할로 쓰시나요` 화면에서 `학생` 또는 `교직원`을 고르고 `선택 완료`를 누릅니다. 두 역할은 가입 뒤 절차가 다릅니다.

| | `학생` | `교직원` |
| --- | --- | --- |
| 승인 | 필요 없음 | 관리자 승인 필요 |
| 가입을 마치면 | 바로 사용 | 승인될 때까지 대기 화면 |
| 하는 일 | 프로그램 신청, 서류 제출 | 프로그램 운영, 신청 판정, 검토 |

<Shot src="staff/role-staff-card.webp" alt="가입 2단계 화면. 학생 카드에는 승인이 필요하지 않다고, 선택된 교직원 카드에는 관리자 승인이 필요하다고 적혀 있습니다." caption="2단계. `교직원`에는 관리자 승인이 필요합니다" />

`관리자`는 이 화면에서 고르지 않습니다. 관리자 접근은 기존 관리자가 계정에 허용합니다. 첫 관리자 계정만 서비스를 처음 열 때 따로 지정합니다. 자세한 내용은 [관리자 가이드](/oss-hub/admin/)를 보세요.

## 3단계. 기본 정보 입력

이름, 학과 등 기본 정보를 입력하고 `가입 마치기`를 누릅니다. 학생은 학번과 전화번호도 입력합니다.

<Shot src="student/signup-profile.webp" alt="가입 3단계 화면. 이름, 학번, 전화번호, 학과 입력칸이 있고 ①이 가입 마치기 버튼을 가리킵니다." caption="3단계. ① 가입 마치기" />

- 학번은 숫자 6자리이고, 처음 한 번만 입력할 수 있습니다. 가입한 뒤에는 바꿀 수 없으니 확인하고 누르세요.
- 학생은 소속으로 `학과`를 골라야 합니다.

입력칸별 규칙과 오류 문구는 [가입하고 프로필 입력하기](/oss-hub/student/sign-up/)에 있습니다.

## 가입이 끝난 뒤

<Success>
학생에게는 대시보드가 열리고 `가입이 완료되었습니다`가 나옵니다. 바로 프로그램을 신청할 수 있습니다.
</Success>

교직원에게는 `교직원 승인을 기다리고 있습니다` 화면이 열립니다. 이 화면에서는 두 가지를 할 수 있습니다.

- `상태 새로고침`: 승인되었는지 확인합니다.
- `이름·학과 고치기`: 잘못 적은 정보를 고칩니다.

<Shot src="staff/pending-waiting.webp" alt="교직원 승인 대기 화면. 승인 대기 표시가 있고 ①이 상태 새로고침 버튼을 가리킵니다. 아래에 이름·학과 고치기 버튼이 있습니다." caption="① 상태 새로고침" />

승인 결과는 알림으로 오지 않으니 이 화면에서 직접 확인해야 합니다. 승인을 서두르려면 관리자에게 알려 주세요.

## 내 역할의 다음 페이지

- `관리자`: [관리자 가이드](/oss-hub/admin/)
- `학생`: [학생 가이드](/oss-hub/student/)
- `교직원`: [교직원 가이드](/oss-hub/staff/)

## 막혔을 때

<Recover title="로그인이나 가입이 안 될 때">
- `로그인 요청을 완료하지 못했습니다. 다시 시도해 주세요.`가 나오면 `로그인`을 다시 누릅니다. 계속 같은 문구가 나오면 계정이 비활성화되었을 수 있으니 관리자에게 문의하세요.
- 동의 화면에서 저장하지 못했다고 나오면 `다시 시도`를 누릅니다.
- 가입을 중간에 멈췄다면 위쪽 `가입 이어하기`로 이어서 합니다.
- 역할을 잘못 골랐다면 3단계의 `역할을 다시 고르기`로 돌아갑니다.
- 교직원 요청이 반려되면 역할 선택 화면이 다시 열리고 `교직원 요청이 반려되었습니다`와 반려 사유가 나옵니다. `교직원`을 다시 고르고 `선택 완료`를 누르면 요청이 새로 접수됩니다. `학생`을 골라 학생으로 가입할 수도 있습니다.
- `접근 권한이 없습니다`가 나오면 `내 화면으로 돌아가기`를 누릅니다. 내 역할에 열려 있지 않은 화면입니다.
- `계정이 비활성화되었습니다`는 설정에서 스스로 비활성화한 직후에 나옵니다. 다시 쓰려면 관리자에게 재활성화를 요청하세요. [계정 비활성화와 재활성화](/oss-hub/admin/deactivate/)를 보세요.
</Recover>
