`운영 대시보드` (operations dashboard) brings together the status of all programs you operate. Start here to decide what needs attention first.

The left-hand `교직원` (staff) menu has three entries.

- `운영 대시보드`: this dashboard.
- `인사이트` (Insights): see [View insights](/oss-hub/en/staff/insights/).
- `가입 신청` (sign-up requests): the queue for staff role requests, not program applications. See [Handle staff role requests](/oss-hub/en/admin/applicants/).

## Find programs that need attention

<Steps>
1. Open `운영 대시보드` in the left menu.
2. Under ① `처리 대기` (pending work), check `검토` (submissions awaiting review) and `신청` (applications awaiting approval). Programs with the most pending work appear first by default.
3. On a wide screen, select `프로그램` (program), `단계 마감` (stage deadline), `제출` (submissions), or `처리 대기` to sort. Select the same heading again to reverse the order.
4. Select a program name to open its overview.
</Steps>

## Check the stage and submission progress

<Steps>
1. Read the active milestone under ② `현재 단계` (current stage). Hover over the stage name and segmented bar, or focus them with the keyboard, to see all stages.
2. Check `단계 마감` for the date and countdown. Hover over the date or focus it with the keyboard to see the exact deadline in Korea Standard Time. For programs marked `모집` (recruiting), this is the application deadline.
3. Hover over or focus the ③ `제출` bar to see how many teams have submitted, how many have not, and how many are expected to submit for the current stage.
</Steps>
<Shot src="staff/dashboard-row.webp" alt="Operations dashboard list on a narrow screen. In the first program, marker ② points to the stage name and segmented bar, and ③ points to the submission bar beside the deadline." caption="② Current stage ③ Submission bar" />

On a narrow screen, the dashboard uses a list instead of a table. Tap the stage, deadline, or submission bar to see its details.

To start a new program, open `프로그램` (programs) in the top navigation and select `프로그램 만들기` (create program). See [Create a program](/oss-hub/en/staff/create-program/).

There is no button in the staff interface to switch to a student view. Use the screenshots in the [student guide](/oss-hub/en/student/) to see what students see.

<Success>

</Success>

<Recover title="If the list is empty">
- `등록된 프로그램이 없습니다` (no programs registered): no programs have been created yet. Click `프로그램 만들기`.
- `검색 결과가 없습니다` (no search results): an older dashboard link may still carry a search or recruitment filter. Select `필터 초기화` (reset filters).
- `운영 대시보드를 불러오지 못했습니다` (could not load the dashboard): click retry. If it keeps happening, ask an administrator to check [System status](/oss-hub/en/admin/system-status/).
</Recover>
