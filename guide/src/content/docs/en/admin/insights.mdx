`인사이트` (Insights) is a read-only view for comparing public GitHub activity and program participation. Administrator access alone does not show this screen. Use an account with approved Staff access.

<Steps>
1. Open ① `인사이트` (Insights) under `교직원` (Staff) in the left menu.
2. In ② the view tabs, choose `순위` (Rankings) for period rankings and `관심 필요` (Needs attention), or `학생 찾기` (Find students) to search and filter. Choose `학과·전공` (Departments and majors) to compare department activity or `프로그램` (Programs) to compare recruitment, composition, completion, and outcomes for published programs.
3. Under ③ `기간` (Period), choose `전체` (All) or a year. This changes period-based activity metrics, not the last-30-days figures or the program scorecard.
</Steps>
<Shot src="staff/insights-full.webp" alt="Insights screen. Marker ① points to Insights in the left menu, ② to the four view tabs, and ③ to the period selector." caption="① `인사이트` (Insights) ② View tabs ③ `기간` (Period)" />

For search, sorting, and metric definitions, see the [Staff Insights guide](/oss-hub/en/staff/insights/).

<Success>
The table and metrics for the selected tab appear. `0` is a measured zero; `—` means the value is missing or cannot be calculated.
</Success>

<Recover title="If the menu is missing or the data cannot load">
- If the menu is missing, check that the account has approved Staff access.
- If the data could not load, select `다시 시도` (Retry). If it still fails, check [System status](/oss-hub/en/admin/system-status/).
</Recover>
