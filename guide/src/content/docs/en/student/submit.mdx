Only approved teams can submit documents. You can't submit without an application or while awaiting approval. You upload documents item by item, not per milestone.

## Open a submission item

<Steps>

1. In program details, under `마일스톤` (Milestones), click a milestone row. The row expands and shows its submission items. The milestone in progress starts expanded.
2. Click `올리기` (Upload) on the item you want to submit. Items you've already submitted show `교체` (Replace) instead.
3. If an item has a `양식` (Template) line, click the filename to download the template.

</Steps>

## Submit in the required format

- For `파일 (필수)` (File, required), choose a file.
- For `내용 (필수)` (Content, required), enter text.
- If an item shows both `내용 (선택)` (Content, optional) and `파일 (선택)` (File, optional), provide at least one. You may submit both.

<Steps>

1. Provide the required text or file. Follow the file formats and size limit shown on screen. Currently, PDF, HWP, and ZIP files up to 5 MB are accepted.
2. If needed, add a `제출 코멘트 (선택)` (Submission comment, optional). It may be left empty and is limited to 2,000 characters.
3. Click `제출` (Submit). The button stays disabled until the required input is provided.

</Steps>

  Once saved, the form closes and the item changes to `검토 대기` (Awaiting review). The item row shows the submission time and the uploaded filename. Open the file with `보기` (View).
</Success>

## Replace a submission

Until the deadline, use `교체` (Replace) on an item awaiting review to submit a new version. The form is the same as the first time, and its button reads `다시 제출` (Resubmit).

Approved, rejected, or closed items have no button. The item row shows only the reason. If you receive a revision request, follow [Resubmit after a revision request](/oss-hub/en/student/resubmit/).

<Recover title="When you can't submit">

- Check whether your application is approved in [Our team](/oss-hub/en/student/my-team/).
- You can't make a first submission after the deadline. If the item has a grace deadline, you can submit until then; submissions after the original deadline are marked late.
- If a file error appears, check the displayed format, size, and archive-file guidance, then select the file again.
- If a message says the submission or review result has changed, what you just entered wasn't saved. Check the latest status, reopen the item, and submit again.

</Recover>
