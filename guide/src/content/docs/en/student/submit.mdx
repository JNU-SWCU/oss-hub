Only approved teams can submit documents. You cannot submit without an application or while awaiting approval.

## Open a submission item

<Steps>

1. In the program's `내 제출물` (My submissions), check the number of required items for each milestone and any revision-request or rejection statuses. `우리 팀` (Our team) shows the same submission status.
2. Click the milestone title. If you used `제출하기` (Submit) beside a milestone or a dashboard link, that milestone's dialog opens directly.
3. Click `올리기` (Upload) for the item you want to submit. Previously submitted items show `수정` (Edit) while editing is allowed.

</Steps>
<Shot src="student/requirement-checklist.webp" alt="Milestone submission dialog, with a status and Upload button for each item. ③ points to Upload on the first unsubmitted item." caption="③ Upload the item you want to submit" />

Expanding a milestone in program details gives you access to the same submission items and templates. If an item has a template file, click its filename to download it.

## Submit in the required format

- For `파일 (필수)` (File, required), choose a file.
- For `내용 (필수)` (Content, required), enter text.
- If an item shows both `내용 (선택)` (Content, optional) and `파일 (선택)` (File, optional), provide at least one. You may submit both.

<Steps>

1. Provide the required text or file. Follow the file formats and size limit shown on screen. Currently, PDF, HWP, and ZIP files up to 5 MB are accepted.
2. If needed, add a `제출 코멘트 (선택)` (Submission comment, optional). It may be left empty for any input format and is limited to 2,000 characters.
3. Click `제출` (Submit). The button stays disabled until the required input is provided.

</Steps>

<Success>
  Once saved, the form closes and the item changes to `검토 대기` (Awaiting review). Check the submission time and the saved version in `제출·검토 이력` (Submission and review history).
</Success>

Before the deadline, use `수정` (Edit) on an item awaiting review to submit a new version. Approved or rejected items cannot be resubmitted. If you receive a revision request, follow [Resubmit after a revision request](/oss-hub/en/student/resubmit/).

<Recover title="When you cannot submit">

- Check whether your application is approved in [Our team](/oss-hub/en/student/my-team/).
- You cannot make a first submission after the deadline. If the item has a grace deadline, you can submit until then; submissions after the original deadline are marked late.
- If a file error appears, check the displayed format, size, and archive-file guidance, then select the file again.
- If a message says the submission or review result has changed, what you just entered was not saved. Check the latest status, reopen the item, and submit again.

</Recover>
