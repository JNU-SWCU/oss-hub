OSS Hub는 전남대학교 SW중심대학사업단의 오픈소스 프로그램을 운영하는 웹 서비스입니다. 학생은 프로그램을 찾아 팀으로 신청하고, 승인을 받으면 GitHub 저장소에서 활동하며 서류를 냅니다. 교직원은 같은 서비스에서 프로그램을 열고 신청을 판정하며 제출물을 검토합니다.

공지와 신청서, 제출 서류, 저장소 활동을 한곳에서 볼 수 있어 메신저나 메일, 스프레드시트를 오가며 확인할 필요가 없습니다. 로그인은 GitHub 계정으로 하므로 별도의 아이디와 비밀번호는 만들지 않습니다.

이 가이드의 화면에 나오는 사람과 프로그램은 설명을 위해 만든 예시입니다.

## 역할별로 하는 일

OSS Hub의 역할은 `관리자`, `학생`, `교직원` 셋입니다. 로그인한 뒤에는 역할에 맞는 메뉴만 보입니다.

| 역할 | 하는 일 | 가이드 |
| --- | --- | --- |
| `관리자` | 교직원 권한 요청을 처리하고 회원 유형과 계정 상태를 바꿉니다. 감사 로그와 시스템 상태도 확인합니다. | [관리자 가이드](/oss-hub/admin/) |
| `학생` | 프로그램을 찾아 팀으로 신청합니다. 승인되면 저장소에서 활동하며 서류를 내고, 보완 요청을 받으면 고쳐서 다시 냅니다. | [학생 가이드](/oss-hub/student/) |
| `교직원` | 프로그램을 만들어 운영하고, 신청을 승인하거나 반려하며, 제출물을 검토합니다. | [교직원 가이드](/oss-hub/staff/) |

회원 유형과 관리자 권한을 따로 관리하므로 한 계정이 `교직원`이면서 `관리자`일 수 있습니다.

## 프로그램 한 건의 흐름

프로그램 하나는 네 단계로 진행됩니다.

1. **탐색.** 학생이 프로그램의 신청 기간, 운영 기간, 제출 일정을 확인합니다.
2. **팀 구성과 신청.** 학생이 팀 이름을 정하고 팀원을 초대한 뒤 신청서를 냅니다. 팀은 신청 화면에서 만들며, 신청서를 제출하면 등록됩니다.
3. **판정.** 교직원이 신청을 `승인`하거나 `반려`합니다. 승인되면 팀은 서류를 낼 수 있고, 프로그램에 따라 팀 저장소가 만들어집니다.
4. **활동·제출·검토.** 팀이 마감 안에 서류를 내면 교직원이 `승인`, `보완 요청`, `반려` 중 하나로 검토합니다. 보완 요청을 받은 팀은 고쳐서 다시 냅니다.

신청 승인과 제출물 검토는 별개입니다. 신청이 승인되어도 각 서류는 따로 검토받습니다.

교직원과 관리자 모두 자기가 속한 팀의 신청은 판정할 수 없고, 제출물도 검토할 수 없습니다.

## 로그인 전에 볼 수 있는 화면

아래 화면은 로그인하지 않아도 열립니다. 신청하거나 제출하려면 로그인해야 합니다.

- **프로그램 목록.** 위쪽 `프로그램`에서 `모집중`, `진행중`, `예정`, `종료` 프로그램을 봅니다.
- **프로그램 상세.** 신청 기간, 운영 기간, 마일스톤을 봅니다. `신청하기` 버튼도 보이는데, 로그인 전에 누르면 GitHub 로그인 화면으로 넘어갑니다.
- **랭킹.** 위쪽 `랭킹`에서 GitHub 활동 순위를 봅니다.
