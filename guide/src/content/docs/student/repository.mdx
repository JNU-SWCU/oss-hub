팀 저장소는 두 경로로 생깁니다. 프로그램이 저장소를 발급하면 승인 때 자동으로 만들어집니다. 직접 만든 공개 저장소를 쓰는 팀은 `우리 팀`에서 주소를 등록합니다.

## 발급된 저장소 확인하기

<Steps>
1. 왼쪽 메뉴에서 `내 저장소`를 엽니다.
2. 저장소 카드의 상태를 확인합니다. `저장소 생성 중`이면 잠시 기다립니다.
3. `초대 수락 대기`이면 GitHub에서 받은 저장소 초대를 직접 수락합니다. OSS Hub는 대신 수락해 주지 않습니다.
4. `GitHub에서 열기`를 눌러 저장소에 들어갑니다.
</Steps>

저장소 생성과 초대 발송은 자동이고, 초대 수락만 직접 합니다. `우리 팀`의 `프로젝트 저장소`에서도 `신청 승인`, `저장소 생성`, `사용 가능` 순서로 발급 단계를 확인합니다. `사용 가능`까지 완료되어도 GitHub 초대는 직접 수락해야 합니다. `운영진에게 문의하세요.`가 보이면 프로그램 담당자에게 문의하세요.

## 직접 만든 저장소 등록하기

팀장만 등록할 수 있고, 신청이 승인된 뒤부터 프로그램이 끝나기 전까지만 가능합니다. 저장소는 GitHub에 공개되어 있어야 합니다.

저장소 주소를 교체하면 이전 저장소의 OSS Hub 등록 정보와 수집 기록이 삭제됩니다. GitHub 원본 저장소는 그대로 남습니다.

<Steps>
1. 대시보드 카드의 `우리 팀`을 열고 `프로젝트 저장소`로 갑니다.
2. ② `변경`을 누르면 같은 카드에서 주소를 편집할 수 있습니다.
3. ③ `저장소 주소`에 GitHub 저장소 주소를 입력합니다.
4. ④ `저장`을 누릅니다. 저장하지 않으려면 `취소`를 누릅니다. 주소를 수정했다면 확인 창에서 `변경사항 버리기`를 누릅니다.
</Steps>

## 저장소 정보와 변경 이력 확인하기

승인된 팀의 팀원은 `프로젝트 저장소`에서 저장소 이름을 눌러 GitHub에서 열 수 있습니다. 정보가 있으면 `기본 브랜치`와 `마지막 수집`이 이름 아래에 나옵니다. 아직 연결하지 않았다면 `연결된 저장소가 없습니다.`가 보입니다.

`변경 이력` 버튼에 조회할 수 있는 건수가 표시될 수 있습니다. 처음 펼칠 때 목록을 불러옵니다. 변경 날짜, 변경한 사람의 GitHub 계정, 이전 저장소와 새 저장소를 확인합니다. `변경 이력 더 보기`가 있으면 눌러서 추가 기록을 불러옵니다. 팀장이 아니어도 이력은 볼 수 있습니다.

<Success>
`저장소 변경을 저장했습니다.`가 나오고 활동 수집이 자동으로 시작됩니다. 수집된 활동은 [활동 보기](/oss-hub/student/activity/)에서 봅니다.
</Success>

<Recover title="등록이 안 될 때">
- 신청이 승인되기 전에는 편집 카드가 보이지 않습니다. 팀장이 아니거나 프로그램이 끝났다면 `변경` 버튼이 비활성화되고 `승인된 팀의 팀장만 프로그램 종료 전까지 변경할 수 있습니다.`가 나옵니다.
- 저장 결과를 확인할 수 없다는 안내가 나오면 `다시 불러오기`로 현재 주소를 확인한 뒤 다시 저장하세요.
- `연결하려는 저장소를 찾을 수 없거나 비공개 저장소입니다. GitHub에 공개된 저장소만 연결할 수 있습니다.` 주소 오타와 공개 여부를 확인하세요.
- `다른 신청에 연결된 저장소입니다.` 다른 팀이 쓰는 저장소입니다.
- `저장소를 처리 중입니다…`: 잠시 뒤 다시 확인하세요.
- `GitHub 저장소를 확인할 수 없습니다…`: GitHub 쪽 문제일 수 있으니 시간을 두고 다시 시도하세요.
- 외부 저장소는 현재 동의 상태도 필요합니다. [가입 동의](/oss-hub/student/sign-up/)를 확인하세요.
- 남의 저장소를 등록할 때의 소유권 확인 기준은 화면에 나와 있지 않습니다. <Verified status="policy" />
</Recover>
