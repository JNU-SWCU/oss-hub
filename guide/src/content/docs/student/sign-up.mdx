OSS Hub에는 별도의 회원가입 양식이 없습니다. GitHub 계정으로 처음 로그인하면 3단계 가입 화면이 이어집니다. 학생 가입에는 승인이 필요하지 않아, 세 단계를 마치면 바로 쓸 수 있습니다.

## 로그인하기

<Steps>
1. 첫 화면 오른쪽 위의 ① `로그인`을 누릅니다.
2. GitHub 로그인 화면에서 계정으로 로그인하고 권한을 허용합니다.
</Steps>

이미 로그인했지만 가입을 마치지 않았다면 `로그인` 대신 `가입 이어하기`가 보입니다. 그 버튼을 누르면 멈춘 단계부터 이어집니다.

<Shot src="intro/login-header.webp" alt="첫 화면 위쪽. ①이 오른쪽 위 로그인 링크를 가리킵니다." caption="① 로그인" />

로그아웃한 뒤 다시 로그인할 때는 GitHub 계정 선택 화면이 먼저 나옵니다. `Signed in as` 옆의 계정이 맞으면 `Continue`를 누르세요.

## 1단계. 개인정보·활동 동의

<Steps>
1. `개인정보 수집·이용`, `GitHub 활동 수집·공개 범위`, `Org 저장소 운영 약관` 세 항목을 읽습니다. 각 항목 오른쪽 `전문 보기`로 전문을 볼 수 있습니다.
2. 세 항목에 모두 체크합니다.
3. `동의하고 계속`을 누릅니다.
</Steps>
<Shot src="student/signup-consent.webp" alt="가입 1단계 화면. 제목은 개인정보·활동 동의이고 동의 항목 세 개와 동의하고 계속 버튼이 있습니다." caption="1단계. 세 항목에 동의한 뒤 `동의하고 계속`" />

화면에는 항상 `비동의시 서비스 이용이 어렵습니다.`가 적혀 있고, 세 항목에 모두 체크하기 전에는 `동의하고 계속`이 눌리지 않습니다. 동의 정책이 바뀌면 다시 동의 화면이 나옵니다.

## 2단계. 역할 선택

<Steps>
1. `학생` 카드를 고릅니다. `학생 가입에는 승인이 필요하지 않습니다`라고 적혀 있습니다.
2. `선택 완료`를 누릅니다.
</Steps>
<Shot src="student/signup-role.webp" alt="가입 2단계 화면. 학생과 교직원 카드가 있고 아래에 선택 완료 버튼이 있습니다." caption="2단계. `학생`을 고르고 `선택 완료`" />

`교직원`은 관리자 승인이 필요한 역할입니다. 잘못 골랐다면 3단계 아래의 `역할을 다시 고르기`로 돌아옵니다.

## 3단계. 기본 정보 입력

<Steps>
1. `이름`을 입력합니다.
2. `학번`에 숫자 6자리를 입력합니다.
3. `전화번호`에 숫자 10~11자리를 입력합니다. 운영진이 선정과 팀 운영 내용을 안내할 때 씁니다.
4. `학과`를 고릅니다.
5. ① `가입 마치기`를 누릅니다.
</Steps>
<Shot src="student/signup-profile.webp" alt="가입 3단계 화면. 이름, 학번, 전화번호, 학과 입력칸이 있고 ①이 가입 마치기 버튼을 가리킵니다." caption="3단계. ① 가입 마치기" />

학번은 처음 한 번만 입력할 수 있고, 가입한 뒤에는 학생이 바꿀 수 없습니다. 입력하기 전에 다시 확인하세요.

<Success>
대시보드가 열리고 `가입이 완료되었습니다` / `이제 프로그램을 신청하고 저장소를 연결할 수 있습니다.`가 나옵니다.
</Success>
<Shot src="student/signup-done.webp" alt="가입을 마친 직후의 대시보드. 위쪽에 가입 완료 안내가 있습니다." caption="가입이 끝난 직후의 대시보드" />

<Recover title="오류 문구가 나올 때">
잘못 입력한 칸 아래에 문구가 나옵니다. 고친 뒤 ① `가입 마치기`를 다시 누르세요.
- `이름을 입력해 주세요.`
- `학번은 숫자 6자리로 입력해 주세요.`
- `이미 다른 계정이 사용 중인 학번입니다. 학번을 다시 확인해 주세요.` 학번이 맞다면 [관리자](/oss-hub/admin/)에게 문의하세요.
- `전화번호는 숫자 10~11자리로 입력해 주세요.`
- `학과를 선택하거나 입력해 주세요.`
- `프로필을 저장하지 못했습니다`: 잠시 뒤 다시 시도하세요.

가입을 중간에 멈췄다면 위쪽 `가입 이어하기`로 이어서 합니다.
</Recover>
