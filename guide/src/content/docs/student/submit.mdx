서류는 승인된 팀이 제출합니다. 신청이 없거나 승인 대기 중이면 제출할 수 없습니다.

## 제출 항목 열기

<Steps>

1. 프로그램의 `내 제출물`에서 마일스톤별 제출 항목 수와 보완·반려 상태를 확인합니다. `우리 팀`에서도 같은 제출 현황을 볼 수 있습니다.
2. 마일스톤 제목을 누릅니다. 마일스톤 옆 `제출하기`나 대시보드 링크로 들어왔다면 해당 마일스톤의 창이 바로 열립니다.
3. 낼 항목의 `올리기`를 누릅니다. 이미 제출한 항목은 수정할 수 있는 동안 `수정`이 표시됩니다.

</Steps>
<Shot src="student/requirement-checklist.webp" alt="마일스톤 제출 창. 항목마다 상태와 올리기 버튼이 있고 ③이 첫 미제출 항목의 올리기를 가리킵니다." caption="③ 낼 항목의 올리기" />

프로그램 상세의 마일스톤을 펼쳐도 같은 제출 항목과 양식을 사용할 수 있습니다. 양식 파일이 등록된 항목은 파일 이름을 눌러 내려받습니다.

## 지정된 형식으로 제출하기

- `파일 (필수)` 항목은 파일을 선택합니다.
- `내용 (필수)` 항목은 글을 입력합니다.
- `내용 (선택)`과 `파일 (선택)`이 함께 있는 항목은 둘 중 하나 이상을 넣습니다. 둘 다 제출해도 됩니다.

<Steps>

1. 항목이 요구하는 내용이나 파일을 넣습니다. 파일은 화면에 표시된 형식과 용량을 따릅니다. 현재 PDF·HWP·ZIP 파일을 5 MB까지 받습니다.
2. 필요하면 `제출 코멘트 (선택)`를 씁니다. 모든 입력 형식에서 비워 두어도 되며 최대 2,000자입니다.
3. `제출`을 누릅니다. 필요한 입력이 없으면 버튼이 활성화되지 않습니다.

</Steps>

<Success>
  저장되면 입력 양식이 닫히고 항목이 `검토 대기`로 바뀝니다. 제출 시각과
  `제출·검토 이력`에서 저장된 제출본을 확인합니다.
</Success>

마감 전에는 검토 대기 항목의 `수정`으로 새 제출본을 낼 수 있습니다. 승인·반려된 항목은 다시 낼 수 없습니다. 보완 요청을 받았다면 [다시 제출하기](/oss-hub/student/resubmit/)를 따릅니다.

<Recover title="제출이 안 될 때">

- 신청 승인 여부를 [우리 팀](/oss-hub/student/my-team/)에서 확인하세요.
- 마감이 지났으면 처음 제출할 수 없습니다. 항목에 유예 기한이 있으면 그 시각까지 제출할 수 있고, 원래 마감 뒤에 낸 제출은 지각으로 표시됩니다.
- 파일 오류가 나면 표시된 형식·용량·압축 파일 안내를 확인하고 파일을 다시 선택하세요.
- 제출본이나 검토 결과가 바뀌었다는 안내가 나오면 방금 작성한 내용은 저장되지 않은 것입니다. 최신 상태를 확인한 뒤 항목을 다시 열어 제출하세요.

</Recover>
