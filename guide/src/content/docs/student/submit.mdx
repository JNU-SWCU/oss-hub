서류는 승인된 팀이 제출합니다. 신청이 없거나 승인 대기 중이면 제출할 수 없습니다. 서류는 마일스톤 단위가 아니라 제출 항목마다 따로 올립니다.

## 제출 항목 열기

<Steps>

1. 프로그램 상세의 `마일스톤`에서 마일스톤 줄을 누릅니다. 줄이 펼쳐지고 제출 항목이 보입니다. 지금 진행 중인 마일스톤은 처음부터 펼쳐져 있습니다.
2. 낼 항목의 `올리기`를 누릅니다. 이미 제출한 항목에는 `올리기` 대신 `교체`가 있습니다.
3. 항목 아래에 `양식` 줄이 있으면 파일 이름을 눌러 양식을 내려받습니다.

</Steps>
<Shot src="student/requirement-checklist.webp" alt="펼친 마일스톤의 제출 항목. ①이 마일스톤 줄, ②가 발표 자료 항목의 올리기, ③이 양식 파일 이름을 가리킵니다. 이미 낸 기획서 항목에는 교체가 있습니다." caption="① 마일스톤 줄, ② 항목의 올리기, ③ 양식 내려받기" />

제출 항목이 하나뿐인 마일스톤은 그 항목의 `올리기`가 마일스톤 줄에 바로 있습니다. 누르면 줄이 펼쳐지고 입력 양식이 열립니다.

<Shot src="student/requirement-row-action.webp" alt="접힌 마일스톤 목록. ①이 항목이 하나인 중간 발표 줄의 올리기를 가리킵니다." caption="① 항목이 하나면 줄에서 바로 올리기" />

`내 제출물`에서도 같은 제출 항목을 볼 수 있습니다. 마일스톤을 누르면 창이 열리고, 창 안의 항목 동작은 위와 같습니다.

## 지정된 형식으로 제출하기

- `파일 (필수)` 항목은 파일을 선택합니다.
- `내용 (필수)` 항목은 글을 입력합니다.
- `내용 (선택)`과 `파일 (선택)`이 함께 있는 항목은 둘 중 하나 이상을 넣습니다. 둘 다 제출해도 됩니다.

<Steps>

1. 항목이 요구하는 내용이나 파일을 넣습니다. 파일은 화면에 표시된 형식과 용량을 따릅니다. 현재 PDF·HWP·ZIP 파일을 5 MB까지 받습니다.
2. 필요하면 `제출 코멘트 (선택)`를 씁니다. 비워 두어도 되며 최대 2,000자입니다.
3. `제출`을 누릅니다. 필요한 입력이 없으면 버튼이 활성화되지 않습니다.

</Steps>

<Shot src="student/requirement-either.webp" alt="내용과 파일이 모두 선택인 항목의 입력 양식. ①이 내용 입력칸과 파일 선택 칸을, ②가 제출 버튼을 가리킵니다." caption="내용이나 파일, 또는 둘 다 제출하는 항목" />

<Success>
  저장되면 입력 양식이 닫히고 항목 상태가 `검토 대기`로 바뀝니다. 항목 줄에서
  제출 시각과 올린 파일 이름을 확인합니다. 파일은 `보기`로 엽니다.
</Success>

## 제출본 바꾸기

검토 대기 중인 항목은 마감 전까지 `교체`로 새 제출본을 낼 수 있습니다. 입력 양식은 처음 제출할 때와 같고, 버튼은 `다시 제출`로 바뀝니다.

승인·반려된 항목이나 마감이 지난 항목에는 버튼이 없고, 항목 줄에 그 이유만 표시됩니다. 보완 요청을 받았다면 [다시 제출하기](/oss-hub/student/resubmit/)를 따릅니다.

<Recover title="제출이 안 될 때">

- 신청 승인 여부를 [우리 팀](/oss-hub/student/my-team/)에서 확인하세요.
- 마감이 지났으면 처음 제출할 수 없습니다. 항목에 유예 기한이 있으면 그 시각까지 제출할 수 있고, 원래 마감 뒤에 낸 제출은 지각으로 표시됩니다.
- 파일 오류가 나면 표시된 형식·용량·압축 파일 안내를 확인하고 파일을 다시 선택하세요.
- 제출본이나 검토 결과가 바뀌었다는 안내가 나오면 방금 작성한 내용은 저장되지 않은 것입니다. 최신 상태를 확인한 뒤 항목을 다시 열어 제출하세요.

</Recover>
