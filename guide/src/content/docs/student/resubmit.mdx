`보완 요청`을 받으면 해당 항목을 다시 낼 수 있습니다. 사유가 없으면 `사유 없이 저장되었습니다.`가 표시됩니다. 고칠 내용을 알 수 없으면 담당 교직원에게 문의하세요.

<Steps>

1. 대시보드 피드백이나 프로그램의 `내 제출물`에서 해당 마일스톤을 엽니다.
2. 항목의 검토 결과와 `제출·검토 이력`을 읽고 `수정`을 누릅니다.
3. 항목이 요구하는 글이나 파일을 넣습니다. 제출 코멘트는 선택입니다. 기존 첨부를 유지하려면 같은 파일을 다시 선택해야 합니다.
4. `다시 제출`을 누릅니다.
5. 마감 뒤에는 `제출하면 더 이상 바꿀 수 없습니다` 확인 창에서 `제출 확정`을 누릅니다.

</Steps>

별도 재제출 만료일은 없습니다. 마일스톤 마감과 유예 규칙은 유지됩니다. 마감 뒤에는 보완 요청 한 건에 한 번만 다시 낼 수 있으며, 제출 후 추가 수정은 교직원의 새 보완 요청이 있어야 가능합니다.

<Success>
  새 제출본은 검토 대기가 되고 이전 제출·검토 기록은 이력에 남습니다.
</Success>

<Recover title="다시 제출할 수 없을 때">
  - 승인·반려된 항목은 다시 낼 수 없습니다. 담당 교직원에게 문의하세요. - 이미
  마감 뒤 보완 요청에 응했다면 같은 요청으로 다시 제출할 수 없습니다. - 제출
  도중 다른 팀원이나 교직원이 상태를 바꾸면 저장을 멈추고 최신 상태를
  불러옵니다. 확인한 뒤 다시 진행하세요. - 입력 형식과 파일 제한은 [서류
  제출하기](/oss-hub/student/submit/)를 보세요.
</Recover>
