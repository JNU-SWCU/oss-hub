초대는 팀장만 보냅니다. 이메일이 아니라 OSS Hub 안의 알림으로 전달되므로, 받는 사람이 로그인해서 확인해야 합니다. 초대 수락과 거절은 받는 사람이 직접 합니다.

## 팀원 초대하기

지원서에서 학생을 지정하면 **최종 제출 때** 초대를 보냅니다. 지정한 학생도 아래의 수락 절차를 거쳐야 실제 팀원이 됩니다. 본인과 지정 인원이 최소 이상이어야 지원할 수 있고, 수락 인원이 최소 이상이어야 승인됩니다.

먼저 [신청서를 제출](/oss-hub/student/apply/)한 뒤 `우리 팀 보기`를 누릅니다. `검토 대기` 상태에서도 초대할 수 있습니다.

지정한 학생이 거절했다면 여기에서 다른 학생을 초대해 수락 인원을 채우세요. 최소 1명인 프로그램에서는 혼자 제출한 뒤 추가 초대를 보내도 됩니다.

<Steps>
1. `우리 팀`의 `팀 구성원`에서 사람 모양 `팀원 초대` 버튼을 누릅니다.
2. `팀원 초대` 패널의 ① `이름 또는 GitHub 아이디로 검색`에 두 글자 이상 입력합니다. 입력하면 자동으로 검색됩니다.
3. 결과에서 초대할 사람 옆 ① `초대`를 누릅니다.
4. 팀 구성원 목록에 그 사람이 `초대 대기`로 나타납니다. 잘못 초대했다면 옆의 `초대 취소`(x)를 누릅니다.
5. 패널은 `닫기`로 닫습니다.
</Steps>

<Shot src="student/invite-search.webp" alt="팀원 검색 결과. ①이 첫 번째 결과의 초대 버튼을 가리킵니다." caption="① 초대" />

승인된 뒤에도 같은 방식으로 초대할 수 있습니다. 초대를 수락해야 팀원에 포함됩니다. 최소 인원은 승인할 때 검사하며 최대 인원과 프로그램당 한 팀 제한은 수락할 때도 검사합니다.

## 초대받기

<Steps>
1. 로그인하면 위쪽 종 모양 `팀 초대 알림`에 초대가 나타납니다. `{이름}님이 초대했습니다` 형태로 팀, 프로그램, 현재 인원이 보입니다.
2. 합류하려면 ① `수락`을, 거절하려면 ② `거절`을 누릅니다.
</Steps>
<Shot src="student/invite-notification.webp" alt="팀 초대 알림 창. 팀 이름과 프로그램이 있고 ①이 수락 버튼, ②가 거절 버튼을 가리킵니다." caption="① 수락 ② 거절" />

<Success>
수락하면 알림에서 초대가 사라지고 `우리 팀`의 구성원 목록에 팀원으로 나타납니다. 최소 인원을 채운 뒤 교직원이 신청을 승인할 수 있습니다. 새 초대가 없으면 `새로운 팀 초대가 없습니다.`가 보입니다.
</Success>

<Recover title="초대가 안 되거나 안 보일 때">
- `이미 이 프로그램의 다른 팀에 소속된 사용자입니다.` 한 프로그램에서는 한 팀에만 속합니다.
- `현재 팀에서 탈퇴한 후 초대를 수락해 주세요.` 수락해도 자동으로 옮겨지지 않습니다. 팀원은 `팀 탈퇴`로 나가고, 팀장은 `신청 취소`로 팀을 삭제하거나 `팀장 위임` 뒤 탈퇴한 다음 다시 수락하세요.
- `이미 대기 중인 초대가 있습니다.` 상대의 답을 기다리거나 `초대 취소` 뒤 다시 보내세요.
- `자기 자신을 초대할 수 없습니다.`, `팀 최대 인원을 초과할 수 없습니다.`
- `활성 학생 계정만 팀원으로 초대할 수 있습니다.` 상대가 가입을 마쳤는지 확인하세요.
- `이미 처리된 초대입니다. 초대 목록을 다시 확인해 주세요.` 이미 수락·거절·취소된 초대입니다.
- 오래된 알림에서 다시 수락·거절·취소하면 `TIV_010`(초대를 찾을 수 없음)이 나올 수 있습니다. 이미 처리된 초대이므로 초대 목록과 `우리 팀`을 새로 확인하세요.
- `팀장만 초대를 관리할 수 있습니다.` 팀원은 초대할 수 없습니다.
- 검색 결과가 없으면 이름이나 GitHub 아이디를 다시 확인하고, 상대가 학생으로 가입했는지 확인하세요.
</Recover>
