`학생`은 OSS Hub에서 프로그램을 찾아 팀으로 신청하고, 승인되면 저장소를 쓰며 서류를 내는 역할입니다. 활동 기록은 대시보드와 랭킹에 쌓입니다.

## 학생이 하는 일

| 하는 일 | 어디서 |
| --- | --- |
| 가입과 프로필 입력 | 첫 로그인 직후 3단계 화면 |
| 프로그램 찾기 | `프로그램` 목록과 프로그램 상세 |
| 팀을 만들고 신청하기 | 프로그램의 신청 화면 |
| 팀원 초대와 초대 수락 | 지원 후 `우리 팀`, 위쪽 `팀 초대 알림` |
| 저장소 확인·연결 | `내 저장소`, 프로그램의 `우리 팀` |
| 서류 제출과 재제출 | 프로그램 상세의 `마일스톤`, `제출 현황` |
| 게시판 | 프로그램의 `게시판` |
| 활동과 랭킹 보기 | `내 활동`, `랭킹` |

## 5분 안에 시작하기

<Steps>
1. 오른쪽 위 `로그인`을 눌러 GitHub 계정으로 로그인합니다.
2. 동의, 역할(`학생`), 기본 정보 세 단계를 끝냅니다. [가입하고 프로필 입력하기](/oss-hub/student/sign-up/)를 보세요.
3. `프로그램`에서 `모집중`인 프로그램을 골라 [신청](/oss-hub/student/apply/)합니다.
4. 승인되면 `내 대시보드`에서 다음 제출 일정을 확인하고 [서류를 냅니다](/oss-hub/student/submit/).
</Steps>

## 업무별 안내

- [가입하고 프로필 입력하기](/oss-hub/student/sign-up/): 처음 로그인했을 때 거치는 세 단계.
- [프로그램 찾기](/oss-hub/student/find-program/): 로그인 없이 보는 목록과 상세.
- [팀을 만들어 신청하기](/oss-hub/student/apply/): 팀 이름, 팀원, 동의, 제출.
- [팀원 초대하고 초대받기](/oss-hub/student/invite/): 초대 보내기와 수락·거절.
- [내 신청과 우리 팀 확인하기](/oss-hub/student/my-team/): 결과 확인, 수정과 취소, 팀 탈퇴.
- [저장소 확인하고 등록하기](/oss-hub/student/repository/): 발급된 저장소와 외부 저장소 연결.
- [서류 제출하기](/oss-hub/student/submit/): 글과 파일 제출.
- [보완 요청을 받고 다시 제출하기](/oss-hub/student/resubmit/): 요청 내용 확인과 재제출.
- [게시판 이용하기](/oss-hub/student/board/): 공지 읽기와 질문 남기기.
- [활동과 랭킹 보기](/oss-hub/student/activity/): 내 활동과 랭킹 확인.
- [내 설정과 계정 비활성화](/oss-hub/student/settings/): 프로필과 알림 변경, 계정 비활성화.

## 헷갈리기 쉬운 점

- 팀은 신청 화면에서 만듭니다. 별도의 팀 만들기 화면이나 참여코드는 없습니다.
- 신청 승인과 서류 검토는 `교직원`이 합니다. 교직원 쪽 화면은 [교직원 가이드](/oss-hub/staff/)에서 설명합니다.
- 계정을 재활성화하는 일은 `관리자`가 합니다. [계정 비활성화와 재활성화](/oss-hub/admin/deactivate/)를 보세요.
