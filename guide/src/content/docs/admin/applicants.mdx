`가입 신청`은 가입한 사람이 `교직원` 역할을 요청하면 쌓이는 대기열입니다. 승인하면 그 계정은 바로 교직원 권한을 얻습니다. 반려하면 사유가 신청자에게 보입니다.

프로그램에 지원한 학생을 심사하는 화면이 아닙니다. 그 일은 프로그램의 `팀 관리`에서 합니다.

이 일은 관리자와 교직원이 모두 할 수 있습니다. 다만 자기 자신의 요청은 처리할 수 없습니다. 대기 중인 요청은 교직원 접근이 아직 없는 계정에만 생깁니다.

처리 결과를 알리는 이메일은 따로 가지 않고, 신청자가 자기 화면에서 상태를 확인합니다. 반려한다면 신청자가 사유를 읽을 수 있도록 구체적으로 적어 주세요.

## 요청 승인하기

<Steps>
1. 왼쪽 `가입 신청`을 엽니다. 요청이 최신순으로 20건씩 나옵니다.
2. 처리할 요청 ①을 누릅니다. 이름이나 GitHub 닉네임으로 찾으려면 위의 검색칸에 입력하고 `검색`을 누릅니다.
3. `프로필`에서 이름과 학과를 확인하고, `대기 중인 요청` 카드의 ① `승인`을 누릅니다.
4. `요청 승인` 창에서 ① `승인 확정`을 누릅니다.
</Steps>

<Shot src="admin/applicant-detail-full.webp" alt="요청 상세 화면. 프로필 카드와 대기 중인 요청 카드가 있고 ①이 승인, ②가 반려 버튼을 가리킵니다." caption="① 승인 ② 반려" />
<Shot src="admin/applicant-approve-dialog.webp" alt="요청 승인 확인 창. ①이 승인 확정 버튼을 가리킵니다." caption="① 승인 확정" />

승인은 확정하는 즉시 적용되니, 누르기 전에 요청한 사람이 맞는지 한 번 더 보세요.

## 요청 반려하기

<Steps>
1. 요청 상세의 ② `반려`를 누릅니다.
2. `반려 사유`에 ① 이유를 적습니다. 입력한 사유는 신청자에게 보이고, 너무 길면 앞부분만 보이므로 핵심부터 적습니다.
3. ② `반려 확정`을 누릅니다.
</Steps>
<Shot src="admin/applicant-reject-dialog.webp" alt="요청 반려 창. ①이 반려 사유 입력칸, ②가 반려 확정 버튼을 가리킵니다." caption="① 반려 사유 ② 반려 확정" />

사유가 비어 있으면 `반려 확정`이 흐리게 바뀌어 눌리지 않습니다.

<Shot src="admin/applicant-reject-dialog-empty.webp" alt="반려 사유가 비어 있는 요청 반려 창. ①이 빈 반려 사유 입력칸을 가리키고 반려 확정 버튼은 흐리게 비활성입니다." caption="① 사유가 비면 `반려 확정`이 눌리지 않음" />

<Success>
화면에 `…님에 대한 요청 승인 처리를 완료했습니다.` 또는 `요청 반려 처리를 완료했습니다.` 알림이 잠깐 나타납니다. 상세 화면은 닫히지 않고 이력만 갱신되니 목록으로 돌아가 다음 요청을 처리하세요. 처리한 요청은 대기열에서 사라집니다. 처리 결과는 [감사 로그](/oss-hub/admin/audit-log/)에 `승인` 또는 `반려`로 남습니다.
</Success>

## 대기열이 비어 있을 때

요청이 없으면 `승인 대기 중인 요청이 없습니다`가 나옵니다. 정상입니다. 검색 결과가 없을 때는 `검색 결과가 없습니다`가 나오고 `필터 초기화`를 누르면 전체 목록으로 돌아갑니다.

<Shot src="admin/applicants-search-empty.webp" alt="검색어에 맞는 요청이 없을 때의 가입 신청 화면. 검색 결과가 없습니다 문구와 필터 초기화 버튼이 보이고 ①이 검색칸을 가리킵니다." caption="① 검색어. 결과가 없을 때의 화면" />

<Recover title="처리가 되지 않을 때">
- `다른 처리자가 먼저 변경했습니다. 최신 정보로 갱신했으니 다시 확인한 뒤 진행해 주세요.`: 다른 사람이 먼저 처리했습니다. 갱신된 화면을 보고 아직 처리가 필요한지 확인하세요.
- `자신의 가입 신청은 처리할 수 없습니다.`: 내 요청은 다른 관리자나 교직원에게 맡기세요.
- `비활성 계정은 승인할 수 없습니다. 계정이 다시 활성화된 뒤에 처리할 수 있습니다.`: 비활성 계정의 상세에서는 `승인` 버튼이 잠기고 이 안내가 버튼 아래에 붙습니다. [계정 재활성화](/oss-hub/admin/deactivate/) 뒤에 다시 승인하세요.
- `역할을 선택하기 전에 온보딩 프로필을 완료해 주세요.`: 프로필이 완성되지 않은 계정은 승인할 수 없습니다. 신청자가 이름, 학번, 학과를 채워야 합니다.
- `요청을 처리하지 못했습니다. 잠시 후 다시 시도해 주세요.`: 잠시 뒤 다시 시도하세요. 반복되면 [시스템 상태](/oss-hub/admin/system-status/)를 확인하세요.
</Recover>
