로그인 직후 어느 화면이 열리는지는 계정에 어떤 권한이 있는지에 따라 달라집니다. 이 페이지에서 내 계정이 어느 쪽인지 확인하고, 앞으로 쓸 메뉴를 찾으세요.

## 관리자 전용 계정

<Steps>
1. 위쪽 `대시보드`를 누릅니다.
2. 왼쪽 `관리자` 묶음의 ① `사용자 목록`이 열립니다. `/dashboard` 주소로 들어가도 같은 화면으로 이동합니다.
</Steps>
<Shot src="admin/entry-admin-only.webp" alt="관리자 전용 계정의 대시보드. 왼쪽 관리자 묶음에 사용자 목록, 감사 로그, 시스템 상태, 학생 활성, 가입 신청이 있고 ①이 사용자 목록을 가리킵니다." caption="관리자 전용 계정. ① 사용자 목록" />

이 계정에는 `운영 대시보드`가 없습니다. 프로그램 모집 현황을 보는 화면이 교직원용이기 때문입니다.

회원 유형이 `학생`인 관리자에게는 `사용자 목록`이 아니라 학생 대시보드가 열립니다. 이 경우 왼쪽 `관리자` 묶음에서 `사용자 목록`을 직접 엽니다.

## 교직원이면서 관리자인 계정

위쪽에 `교직원`과 `관리자` 표시가 함께 보입니다. 왼쪽 메뉴는 두 묶음으로 나뉩니다.

<Steps>
1. 위쪽 `대시보드`를 누르면 ① `운영 대시보드`가 열립니다. 모집중, 진행중, 종료 프로그램 수와 `프로그램 만들기`가 있습니다.
2. 관리 업무는 `관리자` 묶음의 ② `사용자 목록`에서 시작합니다.
</Steps>
<Shot src="admin/entry-staff-and-admin.webp" alt="교직원 겸 관리자 계정의 운영 대시보드. 왼쪽에 교직원 묶음과 관리자 묶음이 있고 ①이 운영 대시보드, ②가 사용자 목록을 가리킵니다." caption="교직원 겸 관리자 계정. ① 운영 대시보드 ② 사용자 목록" />

`학생 활성`과 `가입 신청`은 교직원 권한만으로도 열 수 있습니다. 관리자 전용 계정에서는 이 둘이 `관리자` 묶음 안에 보입니다.

## 프로그램 운영은 어디로 들어가나요

관리자 전용 계정은 `운영 대시보드`가 없으므로 위쪽 `프로그램`에서 들어갑니다.

<Steps>
1. 위쪽 `프로그램`을 누릅니다. 목록에 `프로그램 만들기` 버튼이 보입니다.
2. 프로그램 카드를 눌러 상세 화면을 엽니다.
3. 왼쪽에서 `팀 관리`, `서류 현황`, `게시판`을 고릅니다.
4. 오른쪽 위 ① `편집`으로 프로그램 정보를 고칩니다. 프로그램 삭제도 이 편집 화면에 있습니다.
</Steps>
<Shot src="admin/program-detail-edit.webp" alt="프로그램 상세 화면. 왼쪽에 프로그램 개요, 팀 관리, 서류 현황, 게시판이 있고 ①이 오른쪽 위 편집 버튼을 가리킵니다." caption="프로그램 상세. ① 편집" />

프로그램 운영의 세부 방법은 [교직원 가이드](/oss-hub/staff/)를 보세요. 삭제는 [프로그램 삭제하기](/oss-hub/admin/delete-program/)에서 따로 다룹니다.

<Success>
왼쪽에 `관리자` 묶음이 보이고 `사용자 목록`, `감사 로그`, `시스템 상태`를 열 수 있으면 관리자 접근이 정상입니다.
</Success>

<Recover title="접근 권한이 없습니다가 나올 때">
`접근 권한이 없습니다` / `현재 계정으로는 이 화면을 이용할 수 없습니다.`가 보이면 `내 화면으로 돌아가기`를 누릅니다. 예를 들어 학생 유형이 아닌 관리자가 `내 활동` 주소를 열면 이 안내가 나옵니다. 왼쪽 메뉴는 그대로 있으니 필요한 화면을 다시 고르면 됩니다.

관리자 접근이 있는데도 `관리자` 묶음이 없다면 다른 계정으로 로그인했는지 확인하세요. 그래도 `관리자` 묶음이 보이지 않으면 다른 관리자에게 `사용자 목록`에서 `관리자 접근`이 `허용`인지 봐 달라고 요청하세요.
</Recover>
