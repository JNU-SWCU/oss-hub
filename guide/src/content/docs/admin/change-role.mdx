계정에는 값이 셋 있습니다. 회원 유형은 본인이 가입할 때 정하고, 관리자가 다른 유형으로 바꿀 수 없습니다.

| 값 | 선택지 | 관리자가 할 수 있는 일 |
| --- | --- | --- |
| 회원 유형 | 미지정, 학생, 교직원 | 활동 기록이 없는 계정만 `가입 유형 되돌리기`로 처음 상태로 돌립니다. |
| 관리자 접근 | 허용, 비허용 | 관리자 화면 사용 여부만 바뀝니다. 회원 유형은 그대로입니다. |
| 계정 상태 | 활성, 비활성 | [로그인 가능 여부](/oss-hub/admin/deactivate/)가 바뀝니다. |

## 언제 쓰나요

- 교직원이 학생으로 잘못 가입했을 때: 활동 기록이 없으면 `가입 유형 되돌리기`를 누르고, 본인에게 다시 가입하도록 안내합니다.
- 교직원 권한을 요청받았을 때: [요청 처리](/oss-hub/admin/applicants/)에서 승인하거나 반려합니다.
- 교직원이 업무를 그만두었을 때: 활동 기록이 없으면 `가입 유형 되돌리기`를 씁니다. 활동 기록이 있으면 되돌릴 수 없으니 [계정을 비활성화](/oss-hub/admin/deactivate/)합니다.
- 운영을 함께 맡을 사람이 생겼을 때: 관리자 접근을 `허용`합니다.
- 관리자 업무를 내려놓을 때: 관리자 접근을 `회수`합니다.

관리자 접근은 회원 정보와 모든 계정의 상태를 바꿀 수 있는 권한입니다. 필요한 사람에게만 주고, 맡은 일이 끝나면 회수하세요. 조직의 구체적인 부여 기준은 화면에 나와 있지 않습니다. <Verified status="policy" />

## 상세 화면 열기

<Steps>
1. `사용자 목록`에서 대상 행 끝의 `>`를 누릅니다.
2. 오른쪽 `접근 변경`에서 ① `가입 유형 되돌리기`, ② `관리자 접근`, ③ `계정 상태`를 찾습니다.
</Steps>
<Shot src="admin/user-detail-full.webp" alt="사용자 상세 화면. 오른쪽에 프로필과 접근 변경 카드가 있고 ①이 가입 유형 되돌리기 버튼, ②③이 관리자 접근과 계정 상태 선택칸을 가리킵니다." caption="① 가입 유형 되돌리기 ② 관리자 접근 ③ 계정 상태" />

관리자 접근과 계정 상태는 목록 표의 선택칸으로도 바꿀 수 있습니다. 표의 회원 유형은 글자로만 보이고, 되돌리기는 상세 화면에서만 할 수 있습니다. 변경 전에 이력을 보려면 상세 화면의 `이력` 영역을 확인하세요. `요청 이력`에는 대기, 승인, 반려, 회수 기록이, `로그인 이력`에는 로그인 시각이 나옵니다.

<Shot src="admin/user-history.webp" alt="사용자 상세의 이력 영역. 요청 이력에 승인 한 건, 로그인 이력에 로그인 네 건이 있습니다." caption="요청 이력과 로그인 이력" />

## 가입 유형 되돌리기

계정을 가입 전 상태로 돌립니다. 이름, 학번, 교직원 번호, 학과, 전화번호와 교직원 승인 상태가 지워지고, 지우기 전 값은 이력에 남습니다. 본인은 다음 접속 때 가입 유형을 다시 고릅니다.

<Steps>
1. 상세 화면에서 `가입 유형 되돌리기`를 누릅니다.
2. 같은 이름의 창에서 ① `되돌리기`를 누릅니다.
</Steps>
<Shot src="admin/dialog-reset.webp" alt="가입 유형 되돌리기 창. 프로필이 지워진다는 안내가 있고 ①이 되돌리기 버튼을 가리킵니다." caption="① 되돌리기" />

신청, 팀, 제출, 프로그램 운영 기록처럼 활동 기록이 하나라도 있으면 되돌릴 수 없습니다.

## 관리자 접근 허용·회수하기

<Steps>
1. `관리자 접근`에서 `허용`을 고르면 `관리자 접근 허용` 창이 열립니다. ① `허용 확정`을 누릅니다.
2. 회수하려면 `비허용`을 고르고 `관리자 접근 회수` 창에서 ① `회수 확정`을 누릅니다.
</Steps>
<Shot src="admin/dialog-admin-grant.webp" alt="관리자 접근 허용 창. ①이 허용 확정 버튼을 가리킵니다." caption="허용. ① 허용 확정" />
<Shot src="admin/dialog-admin-revoke.webp" alt="관리자 접근 회수 창. ①이 회수 확정 버튼을 가리킵니다." caption="회수. ① 회수 확정" />

내 계정의 관리자 접근은 회수할 수 없습니다. 그래서 화면에서 마지막 관리자가 사라지는 일은 없습니다. 관리자 업무를 내려놓으려면 다른 관리자를 먼저 지정하고 그 사람에게 회수를 부탁하세요.

## 프로필 고치기

`프로필` 카드의 ① 연필 버튼으로 이름, 학번, 학과를 고칠 수 있습니다. 학번은 학생만 가지며 숫자 6자리이고, 관리자는 이미 저장된 학번도 고칠 수 있습니다. 저장하면 `…님의 프로필을 저장했습니다.`가 나옵니다.

가입을 끝내지 않아 회원 유형이 `미지정`이고 모든 값이 `미등록`인 계정은 프로필을 고쳐도 저장되지 않습니다. 저장 알림은 뜨지만 값이 남지 않습니다. 새로 고쳐 확인한 뒤, 본인에게 가입을 마쳐 달라고 안내하세요.

<Shot src="admin/user-profile-card.webp" alt="사용자 상세의 프로필 카드. 이름, 학번, 학과 등이 있고 ①이 오른쪽 위 연필 버튼을 가리킵니다." caption="① 프로필 편집" />

<Success>
`…님에 대한 가입 유형 되돌리기 처리를 완료했습니다.` 같은 알림에 GitHub 아이디와 변경 종류가 나오고, 화면에 새 값이 보입니다. 종류는 `가입 유형 되돌리기`, `관리자 접근 허용`, `관리자 접근 회수`입니다. 되돌린 계정의 회원 유형은 `미지정`이 됩니다.

[감사 로그](/oss-hub/admin/audit-log/)에는 되돌리기가 `역할 변경`으로, 관리자 접근 허용과 회수가 `기타 작업`으로 남습니다. `기타 작업`의 내용에는 `GRANT_ADMIN_ACCESS` 같은 영문 작업명이 그대로 보입니다.
</Success>

<Recover title="버튼이 잠겨 있거나 변경이 거절될 때">
- `자신의 가입 유형은 되돌릴 수 없습니다.` 내 계정은 되돌릴 수 없습니다.
- `관리자 권한을 먼저 해제해 주세요.` 관리자 접근을 먼저 `비허용`으로 바꾸세요.
- `선택된 가입 유형이 없습니다.` 이미 미지정인 계정이라 되돌릴 것이 없습니다.
- `활동 기록이 있는 계정은 되돌릴 수 없습니다.` 확인 창에 이 문구가 나오면 되돌릴 수 없습니다. 교직원 업무를 그만둔 경우라면 [계정을 비활성화](/oss-hub/admin/deactivate/)하세요.
- 관리자 접근 선택칸에 마우스를 올리면 `자기 계정의 관리자 접근은 회수할 수 없습니다.`가 나옵니다. 내 계정은 다른 관리자가 회수해야 합니다.
- `프로필(이름·학번·학과) 완성 전에는 부여할 수 없습니다.` 선택칸 아래에 이 안내가 보이면 `허용`을 고를 수 없습니다. 안내 문구는 세 값을 모두 요구하지만 교직원은 학번이 없어도 됩니다. 프로필 카드에서 빠진 값을 채우면 `허용`을 고를 수 있습니다. 가입을 끝내지 않은 계정은 본인이 가입을 마쳐야 합니다.
- `접근 상태가 변경되었습니다` / `다른 처리자가 먼저 변경했습니다. 최신 정보로 갱신했으니 다시 확인한 뒤 진행해 주세요.` 다른 관리자가 먼저 바꿨습니다. 갱신된 값을 보고 다시 판단하세요.
- `요청을 처리하지 못했습니다. 잠시 후 다시 시도해 주세요.` 잠시 뒤 다시 시도하세요.
</Recover>
