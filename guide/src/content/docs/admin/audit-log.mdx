`감사 로그`는 누가 언제 무엇을 바꿨는지 확인하는 화면입니다. 권한 변경뿐 아니라 프로그램 운영, 서류 처리와 로그인 기록도 찾습니다. 관리자만 열 수 있으며, 여기서 기록을 고치거나 지우지는 않습니다.

## 화면과 분류 고르기

<Steps>
1. 왼쪽 `관리자` 묶음의 ① `감사 로그`를 엽니다.
2. ② 분류에서 `전체`, `권한·계정`, `운영`, `서류`, `로그인`, `시스템` 중 하나를 고릅니다. 분류는 누르는 즉시 적용됩니다.
3. 넓은 화면에서는 ③ 보기 방식에서 `피드`와 `표`를 전환합니다. 처음에는 `피드`가 열리며, 좁은 화면에서는 `피드`로 봅니다.
</Steps>

<Shot src="admin/audit-full.webp" alt="접힌 로그인 기록이 보이는 감사 로그 피드. ①은 왼쪽 메뉴, ②는 분류, ③은 보기 방식을 가리킵니다." caption="① 감사 로그 메뉴 ② 분류 ③ 보기 방식" />

분류 옆 숫자는 검색어, 작업 종류, 기간에 맞는 기록을 분류별로 센 값입니다. 다른 분류를 골라도 각 분류의 숫자는 유지됩니다.

## 검색과 기간 좁히기

<Steps>
1. `기간`에서 `최근 7일`, `최근 30일`, `직접 지정` 중 하나를 고릅니다. `직접 지정`을 고르면 필요한 `시작일`이나 `종료일`을 입력합니다.
2. `작업 종류`에서 원하는 작업을 고릅니다. 넓은 화면에서는 기간, 날짜, 작업 종류를 바꾸면 바로 적용됩니다.
3. `검색`에 이름이나 GitHub 아이디를 입력하고 Enter 키를 누릅니다. 좁은 화면에서는 먼저 `필터`를 열고 조건을 고른 뒤 `적용`을 누릅니다.
</Steps>

## 피드와 표 읽기

`피드`는 기록을 날짜별로 묶어 최신순으로 보여 줍니다. `전체` 분류에서 작업 종류도 `전체`일 때는 같은 날 이어진 로그인, 로그인 실패, 로그아웃 기록을 한 줄로 접어 보여 줍니다. 요약 줄에서 전체 건수와 실패 건수를 확인하고, 줄을 눌러 개별 기록을 펼칩니다. 묶지 않은 로그인 기록만 보려면 분류에서 `로그인`을 고릅니다.

<Steps>
1. 넓은 화면에서 ① `표`를 누릅니다.
2. ② 표의 `시각`, `행위자`, `작업`, `대상`, `결과` 열에서 개별 기록을 읽습니다. `피드`나 `표`에서 기록을 누르면 `기록 상세`가 열립니다. 변경 전후 값이 있는 기록이면 여기서 확인합니다.
</Steps>

<Shot src="admin/audit-content-closeup.webp" alt="①은 표 보기 버튼을, ②는 로그인 개별 기록 세 건이 있는 표를 가리킵니다." caption="① 표 보기 ② 개별 로그인 기록" />

결과가 여러 페이지면 아래의 `이전`, `다음`으로 이동합니다. 기존 북마크나 검색 링크를 열면 링크에 지정된 조회 범위가 유지됩니다.

작업 종류는 다음처럼 구분합니다.

- 메일 기록은 `작업 종류`에서 `프로그램 메일 발송 시도`, `마감 알림 발송 결과` 등으로 찾습니다. 프로그램 메일에 확인된 실패가 한 건이라도 있으면 `프로그램 메일 일부 실패` 또는 `프로그램 메일 발송 실패`로 표시됩니다.

- 교직원 권한 요청 처리는 `권한 요청 승인`, `권한 요청 반려`, `권한 회수`, `권한 복구`로 찾습니다. `교직원 승인`과 `교직원 승인 회수` 기록도 있습니다.
- 프로그램 신청 처리는 `신청 제출`, `신청 재제출`, `신청 승인`, `신청 반려`, `검토 대기로`로 찾습니다. 교직원 권한 요청과 다른 기록입니다.
- 서류 처리는 `서류 제출`, `서류 재제출`, `서류 수정 요청`, `서류 승인`, `서류 반려`로 찾습니다.
- 회원 유형 기록은 `회원 유형 변경`으로 찾습니다. 처음 유형을 고른 기록의 동작은 `회원 유형 선택`으로 나옵니다.
- 계정 접속은 `로그인`, `로그인 실패`, `로그아웃`으로 찾습니다. 목록에 없는 동작은 원래 코드가 표시될 수 있습니다.

<Success>
조회 조건에 맞는 기록이 나옵니다. `피드`와 `표`를 전환해도 같은 조회 조건과 페이지를 유지합니다.
</Success>

<Recover title="기록이 없거나 불러오지 못할 때">
`기록이 없습니다`와 `조회 조건을 바꿔 보세요.`가 나오면 검색어의 철자와 분류를 확인합니다. 검색어를 지우거나 기간을 넓혀 다시 조회하세요.

`감사 로그를 불러오지 못했습니다. 잠시 후 다시 시도하세요.`가 나오면 `다시 시도`를 누릅니다. 반복되면 [시스템 상태](/oss-hub/admin/system-status/)를 확인하세요.
</Recover>
