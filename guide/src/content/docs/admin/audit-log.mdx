`감사 로그`는 누가 언제 무엇을 바꿨는지 확인하는 화면입니다. 권한 변경뿐 아니라 프로그램 운영, 서류 처리와 로그인 기록도 찾습니다. 관리자만 열 수 있으며, 여기서 기록을 고치거나 지우지는 않습니다.

## 화면과 분류 고르기

<Steps>
1. 왼쪽 `관리자` 묶음의 ① `감사 로그`를 엽니다.
2. ② 분류에서 `전체`, `권한·계정`, `운영`, `서류`, `로그인`, `시스템` 중 하나를 고릅니다. 분류는 누르는 즉시 적용됩니다.
3. ③ 보기 방식에서 `피드` 또는 `표`를 고릅니다. 처음에는 `피드`가 열립니다.
</Steps>
<Shot src="admin/audit-full.webp" alt="감사 로그의 피드 화면. ①은 왼쪽 감사 로그 메뉴, ②는 분류, ③은 피드와 표 전환을 가리킵니다." caption="① 감사 로그 ② 분류 ③ 보기 방식. 그림은 서류 승인 기록을 조회한 예입니다" />

분류 옆 숫자는 검색어, 작업 종류, 기간에 맞는 기록을 분류별로 센 값입니다. 다른 분류를 골라도 각 분류의 숫자는 유지됩니다.

## 검색과 기간 좁히기

<Steps>
1. 필터 그림의 ① `검색`에 이름이나 GitHub 아이디를 입력합니다. 입력 전 보이는 `이름 또는 GitHub 아이디`는 예시 글자입니다.
2. ② `작업 종류`에서 원하는 종류를 고릅니다. 필요하면 `시작일`, `종료일`도 정합니다.
3. ③ `조회`를 누릅니다. 입력하거나 작업 종류를 고르는 것만으로는 조회 조건이 적용되지 않습니다.
</Steps>
<Shot src="admin/audit-filter-bar.webp" alt="감사 로그 필터. ①은 검색 입력칸, ②는 작업 종류, ③은 조회 버튼을 가리킵니다." caption="① 검색 ② 작업 종류 ③ 조회. 날짜 칸의 표기 순서는 브라우저 언어에 따라 다릅니다" />

좁은 화면에서는 `필터`를 눌러 입력칸을 펼칩니다. 버튼 옆 숫자는 현재 적용된 검색어, 작업 종류, 시작일, 종료일 조건의 개수입니다.

아래 그림은 ① `작업 종류`에서 `서류 승인`을 골라 조회한 결과입니다. 조건과 분류를 모두 비우려면 ② `초기화`를 누릅니다. 보기 방식은 그대로 유지됩니다.

<Shot src="admin/audit-filtered.webp" alt="서류 승인 기록 세 건을 조회한 피드. ①은 작업 종류 선택칸, ②는 초기화 버튼을 가리킵니다." caption="① 서류 승인 ② 초기화" />

## 피드와 표 읽기

`피드`는 기록을 날짜별로 묶어 최신순으로 보여 줍니다. 각 줄에는 행위자, 역할, 대상, 동작과 시각이 나옵니다. 변경 값이 있는 기록은 이전 값과 새 값을 화살표로 이어 보여 줍니다. 같은 요청에서 이어진 기록은 들여쓰기로 묶입니다. 로그인 기록에는 별도의 대상이 표시되지 않습니다.

<Steps>
1. 보기 방식의 ① `표`를 누릅니다.
2. ② 표에서 `시각`, `행위자`, `역할`, `동작`, `대상`, `변경`을 확인합니다. 정렬하려면 `변경`을 제외한 열 제목을 누릅니다. 같은 제목을 다시 누르면 방향이 바뀝니다.
</Steps>
<Shot src="admin/audit-content-closeup.webp" alt="표 보기의 감사 로그. ①은 표 전환 버튼, ②는 시각, 행위자, 역할, 동작, 대상, 변경 열을 가진 표를 가리킵니다." caption="① 표 보기 ② 기록과 변경 값" />

정렬은 현재 페이지의 기록 안에서만 바뀝니다. 좁은 화면에서는 `시각`과 `행위자` 아래에 나머지 정보가 모이고, `정렬` 선택칸과 `오름차순` 또는 `내림차순` 버튼을 씁니다. 아래의 `이전`, `다음`으로 페이지를 넘깁니다. 한 페이지에는 최대 20건이 나옵니다.

작업 종류는 다음처럼 구분합니다.

- 교직원 권한 요청 처리는 `권한 요청 승인`, `권한 요청 반려`, `권한 회수`, `권한 복구`로 찾습니다. `교직원 승인`과 `교직원 승인 회수` 기록도 있습니다.
- 프로그램 신청 처리는 `신청 제출`, `신청 재제출`, `신청 승인`, `신청 반려`, `검토 대기로`로 찾습니다. 교직원 권한 요청과 다른 기록입니다.
- 서류 처리는 `서류 제출`, `서류 재제출`, `서류 수정 요청`, `서류 승인`, `서류 반려`로 찾습니다.
- 회원 유형 기록은 `회원 유형 변경`으로 찾습니다. 처음 유형을 고른 기록의 동작은 `회원 유형 선택`으로 나옵니다.
- 계정 접속은 `로그인`, `로그인 실패`, `로그아웃`으로 찾습니다. 목록에 없는 동작은 원래 코드가 표시될 수 있습니다.

<Success>
조회 조건에 맞는 기록과 아래 `총 N건`이 바뀝니다. `피드`와 `표`를 전환해도 같은 조회 조건과 페이지를 유지합니다.
</Success>

<Recover title="기록이 없거나 불러오지 못할 때">
`기록이 없습니다`와 `조회 조건을 바꿔 보세요.`가 나오면 조건에 맞는 기록이 없다는 뜻입니다. 검색어의 철자와 분류, 기간을 확인하고 `초기화`로 다시 시작하세요.

<Shot src="admin/audit-empty.webp" alt="검색 결과가 없는 감사 로그. ①은 검색어를 가리키고 아래에 기록이 없습니다 안내와 총 0건이 보입니다." caption="① 검색어와 일치하는 기록이 없는 상태" />

`감사 로그를 불러오지 못했습니다. 잠시 후 다시 시도하세요.`가 나오면 `다시 시도`를 누릅니다. 반복되면 [시스템 상태](/oss-hub/admin/system-status/)를 확인하세요.
</Recover>
