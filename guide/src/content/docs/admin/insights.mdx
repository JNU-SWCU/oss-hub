`학생 활성` 화면에서는 전공별 GitHub 활동과 프로그램 참여를 비교합니다. 사업의 효과를 설명하거나 어느 쪽에 참여가 적은지 볼 때 엽니다. 교직원과 관리자가 열 수 있고, 데이터를 바꾸지는 않습니다.

<Steps>
1. 왼쪽에서 ① `학생 활성`을 엽니다.
2. `기간`에서 `전체`나 연도를 고릅니다.
3. `비교 관점`에서 `전공·비전공` 또는 `학과`를 고릅니다.
</Steps>

## 숫자 읽기

- `가입 학생`: 가입한 학생 수입니다.
- `활동 학생`: 활동 기준을 채운 학생 수입니다. 활동 기준은 랭킹 합계 1 이상입니다.
- `프로그램 참여자`: 프로그램 참여가 승인된 학생 수입니다.
- `활성 — 랭킹 지표`: Commit, PR, Issue, Repo, Star(누적), 합계를 비교합니다.
- `학과별 활성`: 학과별 학생과 활동을 비교합니다.
- `참여 — 프로그램별`: 프로그램마다 승인된 참여를 보여 줍니다.

`활성 — 랭킹 지표` 차트 세로축의 숫자 일부가 잘려 보일 수 있습니다. 축 숫자만 보고 값을 옮겨 적지 말고, 막대에 마우스를 올려 나오는 값을 확인하세요.

<Success>
선택한 기간과 비교 관점에 맞게 숫자와 차트가 바뀌고, 위쪽에 `기간 전체 · 기준 …` 같은 한 줄이 함께 나옵니다.
</Success>

<Recover title="비어 있거나 불러오지 못할 때">
`학과별 학생이 없습니다`, `승인된 참여가 없습니다`는 해당 기간에 집계할 값이 없다는 뜻입니다. `기간`을 `전체`로 넓혀 보세요. `학생 활성을 불러오지 못했습니다`가 나오면 화면을 새로 고치세요.
</Recover>
