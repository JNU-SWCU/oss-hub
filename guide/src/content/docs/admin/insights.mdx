`인사이트`는 공개 GitHub 활동과 프로그램 참여를 비교하는 조회 화면입니다. 관리자 권한만 있는 계정에는 보이지 않습니다. 승인된 교직원 권한이 있는 계정으로 여세요.

<Steps>
1. 왼쪽 `교직원` 메뉴에서 ① `인사이트`를 엽니다.
2. ② `순위`에서는 기간별 학생 순위와 `관심 필요`를, `학생 찾기`에서는 검색과 필터로 찾은 학생을 봅니다. `학과·전공`에서는 학과별 활동을, `프로그램`에서는 게시된 프로그램의 모집·구성·완주·성과를 비교합니다.
3. ③ `기간`에서 `전체`나 연도를 고릅니다. 기간별 활동 지표만 바뀌며 최근 30일 집계와 프로그램 성과표에는 적용되지 않습니다.
</Steps>
<Shot src="staff/insights-full.webp" alt="인사이트 화면. ①은 왼쪽 메뉴의 인사이트, ②는 순위, 학생 찾기, 학과·전공, 프로그램 탭, ③은 기간 선택을 가리킵니다." caption="① `인사이트` ② 보기 탭 ③ `기간`" />

검색·정렬 방법과 탭별 지표의 뜻은 [교직원 인사이트 안내](/oss-hub/staff/insights/)를 보세요.

<Success>
선택한 탭의 표와 지표가 보입니다. `0`은 집계 결과이고 `—`는 값이 없거나 계산할 수 없다는 뜻입니다.
</Success>

<Recover title="메뉴가 보이지 않거나 불러오지 못할 때">
- 메뉴가 없으면 계정에 승인된 교직원 권한이 있는지 확인하세요.
- 불러오지 못했다는 안내가 나오면 `다시 시도`를 누르세요. 반복되면 [시스템 상태](/oss-hub/admin/system-status/)를 확인하세요.
</Recover>
