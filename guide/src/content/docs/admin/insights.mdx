`인사이트` 화면에서는 학생 상위 활동, 학과·전공별 현황, 프로그램 참여 순위를 봅니다. 사업의 효과를 설명하거나 어느 쪽에 참여가 적은지 볼 때 엽니다. 승인된 교직원이 열 수 있고, 데이터를 바꾸지는 않습니다. 관리자 접근만 있는 계정에는 보이지 않습니다.

<Steps>
1. 왼쪽 메뉴에서 ① `인사이트`를 엽니다.
2. 제목 아래 밑줄 탭에서 ② `학생` / `학과·전공` / `프로그램`을 고릅니다.
3. ③ `기간`에서 `전체`나 연도를 고릅니다. 기간은 `학생` 탭 순위와 활동 숫자(`활동률`, `1인당 활동량`)에 적용됩니다. 가입 학생 수와 참여 숫자(`학과·전공` 탭의 `프로그램 참여율`, `프로그램` 탭)는 기간과 상관없이 현재 상태를 보여 줍니다.
</Steps>

## 탭별로 보이는 내용

- `학생` 탭: `전체` / `SW전공` / `비SW전공` 필터를 고릅니다. 넓은 화면에서는 카드 두 개가 나란히 보입니다.
  - `<기간> 상위 10명`: 고른 기간의 공개 활동(Commit·PR·Issue·Repo·Star) 합계 순위입니다.
  - `최근 30일 상위 10명`: 최근 30일 동안 늘어난 Commit·PR·Issue·Repo 합계 순위입니다. Star는 빼고, 집계 기간(from~to 날짜)이 함께 나옵니다.
  - 각 줄에는 순위, 이름(이름이 없으면 GitHub 로그인), 학과(없으면 `학과 미등록`), `@login`, 합계, 크기에 비례한 막대가 나옵니다. 학번은 보이지 않습니다.
  - 공개 활동만 세므로 공개 랭킹 페이지의 숫자와 다를 수 있습니다.
- `학과·전공` 탭: `SW전공`과 `비SW전공` 카드에 `가입 학생`, `활동률`(활동 학생 / 가입 학생), `프로그램 참여율`(참여 학생 / 가입 학생)이 나오고, `학과 미등록` 학생 수도 따로 보입니다. `가입 학생`과 `학과 미등록` 카드에는 `현재 가입 기준 · 기간 미적용`, `프로그램 참여율` 카드에는 `현재 승인 기준 · 기간 미적용`이 함께 보여 기간과 상관없는 숫자임을 알려 줍니다. 아래 학과 순위 차트는 `가입 학생 수`와 `1인당 활동량` 중에서 고릅니다. `1인당 활동량`에서는 가입 학생이 3명 미만인 학과를 `표본 적음 (가입 3명 미만)`으로 따로 모아 보여 줍니다.
- `프로그램` 탭: `프로그램 참여 순위`입니다. 승인된 신청자와 팀원을 중복 없이 센 수로 프로그램을 줄 세우고, SW전공 / 비SW전공 / 학과 미등록으로 쌓아 보여 줍니다. 이 탭에는 `기간`이 적용되지 않습니다.

탭은 주소로도 열 수 있습니다: `?view=students`, `?view=groups`, `?view=programs`.

<Success>
선택한 기간과 탭에 맞게 숫자와 차트가 바뀌고, 위쪽에 기간과 데이터 기준 시각이 함께 나옵니다.
</Success>

<Recover title="비어 있거나 불러오지 못할 때">
고른 기간에 집계할 값이 없으면 비어 있을 수 있습니다. `기간`을 `전체`로 넓혀 보세요. 불러오지 못했다는 안내가 나오면 화면을 새로 고치세요.
</Recover>
