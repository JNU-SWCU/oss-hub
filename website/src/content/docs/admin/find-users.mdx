`사용자 목록`은 역할, 계정 상태, 마지막 로그인을 한 번에 보고 바꾸는 화면입니다. 역할을 바꾸거나 계정을 멈추기 전에 대상이 맞는지 여기서 확인합니다. 관리자만 열 수 있습니다.

## 계정 찾기

<Steps>
1. 왼쪽 `관리자` 묶음에서 `사용자 목록`을 엽니다.
2. ① 검색칸에 `이름 또는 GitHub 닉네임`을 입력합니다.
3. 역할로 좁히려면 ② `전체 역할`에서 미지정, 학생, 교직원, 관리자 중 하나를 고릅니다.
4. 상태로 좁히려면 ③ `전체 상태`에서 활성 또는 비활성을 고릅니다.
5. `검색`을 누릅니다.
</Steps>
<Shot src="admin/users-filters.webp" alt="사용자 목록의 검색 영역. ①이 검색칸, ②가 전체 역할, ③이 전체 상태를 가리킵니다." caption="① 검색 ② 전체 역할 ③ 전체 상태" />

비활성 계정만 보려면 `전체 상태`를 `비활성`으로 두고 `검색`을 누릅니다.

<Shot src="admin/users-filter-inactive.webp" alt="전체 상태를 비활성으로 고른 사용자 목록. ①이 비활성 선택을 가리킵니다." caption="① 비활성 선택" />

## 표 읽기

한 페이지에 20명이 이름순으로 나옵니다. 아래의 `이전`, `다음`으로 넘기고, `1 / 1 페이지 (총 3명)`처럼 전체 인원이 표시됩니다. 열 머리글을 누르면 정렬이 바뀝니다.

| 열 | 뜻 |
| --- | --- |
| `사용자` | 이름과 GitHub 닉네임. 이름이 없으면 `이름 미등록`. |
| `회원 유형` | 미지정, 학생, 교직원 중 하나. |
| `관리자 접근` | `허용` 또는 `비허용`. 회원 유형과 별개입니다. |
| `계정 상태` | `활성` 또는 `비활성`. |
| `가입 일시` | 처음 가입한 때. |
| `마지막 로그인` | 로그인한 적이 없으면 `기록 없음`. |

<Shot src="admin/users-list.webp" alt="사용자 목록 표. 사용자, 회원 유형, 관리자 접근, 계정 상태, 가입 일시, 마지막 로그인 열이 있고 ①이 첫 행의 회원 유형 선택칸을 가리킵니다." caption="① 표 안에서 바로 바꾸는 회원 유형 선택칸" />

회원 유형, 관리자 접근, 계정 상태는 서로 독립된 값입니다. 회원 유형이 `교직원`이어도 관리자 접근은 `비허용`일 수 있습니다. 반대로 관리자 접근을 `허용`해도 회원 유형은 그대로입니다.

이름 밑에 붙는 표시는 이렇게 읽습니다.

- `요청 대기`: 처리하지 않은 교직원 권한 요청이 있습니다. 먼저 [요청을 처리](/oss-hub/admin/applicants/)해야 회원 유형을 바꿀 수 있습니다.
- `프로필 미완료`: 이름, 학번, 학과 중 빠진 것이 있습니다.

<Shot src="admin/users-badge-pending.webp" alt="사용자 목록에서 요청 대기 표시가 붙은 행. ①이 요청 대기 표시를 가리킵니다." caption="① 요청 대기 표시" />

행 끝의 `>`를 누르면 그 사람의 상세 화면이 열립니다. 상세는 [회원 유형과 관리자 접근 바꾸기](/oss-hub/admin/change-role/)에서 설명합니다.

<Success>
검색 조건에 맞는 계정만 남고 아래에 `총 N명`이 바뀝니다.
</Success>

<Recover title="목록이 비었을 때">
조건을 바꿔도 결과가 없다면 검색어의 철자와 `전체 역할`, `전체 상태` 선택을 확인하세요. 두 선택을 모두 처음 값으로 돌린 뒤 검색어만 남기면 원인을 좁히기 쉽습니다.
</Recover>
