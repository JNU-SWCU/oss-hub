비활성화된 계정은 로그인할 수 없습니다. 계정을 지우는 기능이 아니라 로그인을 막는 기능이고, 다시 활성화하면 되돌아옵니다.

## 계정 비활성화하기

접근을 바로 막아야 할 때 씁니다. 비활성화하면 그 사람은 로그인할 수 없습니다. 활성 관리자가 한 명뿐일 때와 내 계정에는 쓸 수 없습니다.

<Steps>
1. `사용자 목록`에서 대상 계정의 상세 화면을 엽니다.
2. `접근 변경`의 `계정 상태`에서 `비활성`을 고릅니다.
3. `계정 비활성화` 창의 ① `비활성화 확정`을 누릅니다.
</Steps>
<Shot src="admin/dialog-deactivate.webp" alt="계정 비활성화 확인 창. ①이 비활성화 확정 버튼을 가리킵니다." caption="① 비활성화 확정" />

## 계정 재활성화하기

학생이 스스로 비활성화한 뒤 다시 쓰고 싶다고 요청할 때도 아래 방법으로 재활성화합니다. 계정을 스스로 비활성화한 사용자에게는 `계정이 비활성화되었습니다` 화면이 나오고, 관리자에게 재활성화를 요청하라고 안내합니다.

<Shot src="admin/account-deactivated.webp" alt="비활성화된 사용자가 로그아웃된 뒤 보는 화면. 재활성화를 관리자에게 요청하라는 안내와 ①홈으로 돌아가기 버튼이 있습니다." caption="비활성화된 사용자가 보는 화면. ① 홈으로 돌아가기" />

<Steps>
1. `사용자 목록`에서 `전체 상태`를 `비활성`으로 고르고 `검색`을 누릅니다.
2. 대상 계정의 상세 화면에서 `계정 상태`를 `활성`으로 고릅니다.
3. `계정 재활성화` 창의 ① `재활성화 확정`을 누릅니다.
</Steps>
<Shot src="admin/dialog-reactivate.webp" alt="계정 재활성화 확인 창. ①이 재활성화 확정 버튼을 가리킵니다." caption="① 재활성화 확정" />

비활성화는 `계정 상태`만 바꾸고 `회원 유형`과 `관리자 접근`은 그대로 둡니다. 그래서 재활성화하면 비활성화 전에 가졌던 권한이 그대로 살아납니다. 확정하기 전에 두 값을 보고 지금도 맞는지 확인하세요.

스스로 비활성화한 계정인지 관리자가 비활성화한 계정인지는 목록에서 구분되지 않습니다. 두 경우 모두 처리 방식은 같습니다. 확인하려면 [감사 로그](/oss-hub/admin/audit-log/)에서 `계정 상태 변경`을 찾으세요. 행위자와 대상이 같은 사람이면 스스로 비활성화한 것입니다.

<Success>
`…님에 대한 계정 비활성화 처리를 완료했습니다.` 또는 `계정 재활성화 처리를 완료했습니다.`가 나오고 `계정 상태`가 바뀝니다.
</Success>

<Recover title="거절될 때">
- 내 계정에서는 비활성화 선택지가 잠기고, 마우스를 올리면 `자기 계정은 비활성화할 수 없습니다.`가 나옵니다. 내 계정은 이 화면에서 멈출 수 없습니다. 방법은 [내 설정](/oss-hub/admin/my-settings/)에 있습니다.
- `활성 관리자 계정을 최소 한 개 유지해야 합니다.`: 마지막 활성 관리자입니다. 다른 관리자를 먼저 지정하세요.
- `사용자 접근 상태가 조회 당시와 달라졌습니다.`: 화면을 새로 고치고 다시 시도하세요.
</Recover>
