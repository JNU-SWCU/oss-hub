`감사 로그`는 관리 작업 이력이 남는 화면입니다. 권한을 누가 바꿨는지, 프로그램을 누가 지웠는지처럼 나중에 확인해야 할 일을 찾을 때 엽니다. 관리자만 열 수 있고, 여기서는 기록을 조회만 합니다.

## 기록 조회하기

<Steps>
1. 왼쪽 `관리자` 묶음의 ① `감사 로그`를 엽니다.
2. ① `행위자`에 GitHub 아이디를 입력합니다. 특정 사람의 작업만 볼 때 씁니다.
3. ② `작업 종류`에서 원하는 종류를 고릅니다. 기본값은 `전체`입니다.
4. 기간을 좁히려면 `시작일`, `종료일`을 고릅니다.
5. ③ `조회`를 누릅니다.
</Steps>

<Shot src="admin/audit-filter-bar.webp" alt="감사 로그의 조회 조건 영역. ①이 행위자, ②가 작업 종류, ③이 조회 버튼을 가리킵니다." caption="① 행위자 ② 작업 종류 ③ 조회" />

조건을 모두 비우려면 `초기화`를 누릅니다.

<Shot src="admin/audit-filtered.webp" alt="작업 종류를 승인으로 고른 감사 로그. ①이 작업 종류, ②가 초기화 버튼을 가리키고 결과는 총 3건입니다." caption="① 작업 종류 `승인` ② 초기화" />

## 표 읽기

열은 `발생 일시`, `행위자`, `대상`, `내용`입니다. 시각은 `3일 전` 같은 상대 표현과 정확한 시각이 함께 나옵니다. `내용`에는 "…님이 …님의 교직원 권한 요청을 승인했습니다"처럼 한 문장이 나오고, 앞에 작업 종류 표시가 붙습니다. 아래에 `총 N건`이 나오고 `이전`, `다음`으로 쪽을 넘깁니다.

<Shot src="admin/audit-content-closeup.webp" alt="감사 로그 표의 확대 화면. 발생 일시, 행위자, 대상, 내용 열과 작업 종류 표시가 보입니다." caption="내용 열의 문장과 작업 종류 표시" />

작업 종류는 이렇게 묶여 있습니다.

| 묶음 | 종류 |
| --- | --- |
| 권한·계정 | 승인, 반려, 회수, 복구, 역할 변경, 계정 상태 변경, 프로필 수정, 전화번호 수정 |
| 저장소 | 저장소 공개, 저장소 연결 변경 |
| 프로그램 | 생성, 보관, 복구, 삭제 |
| 팀 | 생성, 합류, 이름 변경, 삭제, 구성 변경 |
| 수집 | 수집 실행, 제출 파일 정리 재시도 |
| 신청 | 신청 제출, 신청 승인, 신청 반려, 검토 대기로 |

`승인`과 `신청 승인`은 다릅니다. `승인`은 [교직원 권한 요청](/oss-hub/admin/applicants/)을 승인한 기록이고, `신청 승인`은 프로그램 지원자를 승인한 기록입니다. 목록에 없는 종류는 `기타 작업`으로 나옵니다.

<Success>
조건에 맞는 기록이 최신순으로 나오고 아래 `총 N건`이 바뀝니다.
</Success>

<Recover title="기록이 없거나 불러오지 못할 때">
`기록이 없습니다` / `조회 조건을 바꿔 보세요.`가 나오면 조건에 맞는 기록이 없다는 뜻입니다. `행위자`의 철자와 기간을 확인하고 `초기화`로 다시 시작하세요.

<Shot src="admin/audit-empty.webp" alt="기록이 없는 감사 로그. ①이 일치하는 기록이 없는 행위자 입력값을 가리킵니다." caption="① 일치하는 기록이 없는 행위자" />

`감사 로그를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요.`가 나오면 `다시 시도`를 누르세요. 반복되면 [시스템 상태](/oss-hub/admin/system-status/)를 확인하세요.
</Recover>
