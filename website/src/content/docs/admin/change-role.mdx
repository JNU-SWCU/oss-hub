계정에는 서로 독립된 값이 셋 있습니다. 하나를 바꿔도 나머지는 그대로입니다.

| 값 | 선택지 | 바꾸면 |
| --- | --- | --- |
| 회원 유형 | 미지정, 학생, 교직원 | 학생과 교직원 사이를 오가며 교직원 접근 권한이 부여되거나 해제됩니다. |
| 관리자 접근 | 허용, 비허용 | 관리자 화면 사용 여부만 바뀝니다. 다른 접근 권한은 변경되지 않습니다. |
| 계정 상태 | 활성, 비활성 | [로그인 가능 여부](/oss-hub/admin/deactivate/)가 바뀝니다. |

## 언제 바꾸나요

- 학생을 교직원으로 올릴 때: 보통 사용자가 `가입 신청`으로 요청하므로 [요청 처리](/oss-hub/admin/applicants/)로 끝납니다. 요청 없이 직접 지정해야 할 때만 여기서 바꿉니다.
- 교직원이 업무를 그만두었을 때: 회원 유형을 `학생`으로 바꾸면 교직원 접근 권한이 해제됩니다. 이 변경은 요청 이력에 `회수`로 남습니다.
- 운영을 함께 맡을 사람이 생겼을 때: 관리자 접근을 `허용`합니다.
- 관리자 업무를 내려놓을 때: 관리자 접근을 `회수`합니다.

관리자 접근은 회원 정보와 모든 계정의 상태를 바꿀 수 있는 권한입니다. 필요한 사람에게만 부여하고, 맡은 일이 끝나면 회수하세요. 조직의 구체적인 부여 기준은 화면에 나와 있지 않습니다. <Verified status="policy" />

## 상세 화면 열기

<Steps>
1. `사용자 목록`에서 대상 행 끝의 `>`를 누릅니다.
2. 오른쪽 `접근 변경`에서 ① `회원 유형`, ② `관리자 접근`, ③ `계정 상태` 선택칸을 찾습니다.
</Steps>
<Shot src="admin/user-detail-full.webp" alt="사용자 상세 화면. 오른쪽에 프로필과 접근 변경 카드가 있고 ①②③이 회원 유형, 관리자 접근, 계정 상태 선택칸을 가리킵니다." caption="① 회원 유형 ② 관리자 접근 ③ 계정 상태" />

목록 표의 선택칸으로도 같은 변경을 할 수 있습니다. 변경 전에 이력을 보려면 상세 화면의 `이력` 영역을 확인하세요. `요청 이력`에는 대기, 승인, 반려, 회수 기록이, `로그인 이력`에는 로그인 시각이 나옵니다.

<Shot src="admin/user-history.webp" alt="사용자 상세의 이력 영역. 요청 이력에 승인 한 건, 로그인 이력에 로그인 네 건이 있습니다." caption="요청 이력과 로그인 이력" />

## 학생으로 바꾸기

교직원 접근 권한이 해제됩니다.

<Steps>
1. `회원 유형`에서 `학생`을 고릅니다.
2. `학생으로 변경` 창에 저장된 학번이 없으면 ① `학번`에 숫자 6자리를 입력합니다. 학과도 저장된 값이 없을 때만 입력칸이 나오고, 있으면 `저장된 학번을 사용합니다.`처럼 안내만 보입니다.
3. ② `변경`을 누릅니다.
</Steps>
<Shot src="admin/dialog-to-student.webp" alt="학생으로 변경 창. ①이 학번 입력칸, ②가 변경 버튼을 가리킵니다." caption="① 학번 ② 변경" />

## 교직원으로 바꾸기

교직원 접근 권한이 부여됩니다.

<Steps>
1. `회원 유형`에서 `교직원`을 고릅니다.
2. `교직원으로 변경` 창의 ① `교직원 번호 (선택)`은 비워 둬도 됩니다. 입력한다면 사번을 적습니다. 이미 등록된 번호를 비우고 변경하면 번호가 삭제됩니다.
3. ② `변경`을 누릅니다.
</Steps>
<Shot src="admin/dialog-to-staff.webp" alt="교직원으로 변경 창. ①이 교직원 번호 입력칸, ②가 변경 버튼을 가리킵니다." caption="① 교직원 번호 ② 변경" />

## 관리자 접근 허용·회수하기

<Steps>
1. `관리자 접근`에서 `허용`을 고르면 `관리자 접근 허용` 창이 열립니다. ① `허용 확정`을 누릅니다.
2. 회수하려면 `비허용`을 고르고 `관리자 접근 회수` 창에서 ① `회수 확정`을 누릅니다.
</Steps>
<Shot src="admin/dialog-admin-grant.webp" alt="관리자 접근 허용 창. ①이 허용 확정 버튼을 가리킵니다." caption="허용. ① 허용 확정" />
<Shot src="admin/dialog-admin-revoke.webp" alt="관리자 접근 회수 창. ①이 회수 확정 버튼을 가리킵니다." caption="회수. ① 회수 확정" />

내 계정의 관리자 접근은 회수할 수 없고, 활성 관리자가 한 명뿐일 때도 회수가 거절됩니다. 다른 관리자를 먼저 지정하세요.

## 프로필 고치기

`프로필` 카드의 ① 연필 버튼으로 이름, 학번, 교직원 번호, 학과를 고칠 수 있습니다. 학번은 숫자 6자리이고, 관리자는 이미 저장된 학번도 고칠 수 있습니다. 저장하면 `…님의 프로필을 저장했습니다.`가 나옵니다.

<Shot src="admin/user-profile-card.webp" alt="사용자 상세의 프로필 카드. 이름, 학번, 교직원 번호, 학과가 있고 ①이 오른쪽 위 연필 버튼을 가리킵니다." caption="① 프로필 편집" />

<Success>
`…님에 대한 학생 유형 적용 처리를 완료했습니다.`처럼 변경 종류가 들어간 알림이 나옵니다. 종류는 `학생 유형 적용`, `교직원 유형 적용`, `관리자 접근 허용`, `관리자 접근 회수`입니다. 선택칸에 새 값이 보이고 [감사 로그](/oss-hub/admin/audit-log/)에 `역할 변경`으로 남습니다.
</Success>

<Recover title="선택칸이 잠겨 있거나 변경이 거절될 때">
- `대기 중인 요청을 먼저 처리해 주세요.`: 회원 유형 선택칸이 회색으로 잠기고 이 문구가 붙습니다. [가입 신청](/oss-hub/admin/applicants/)에서 승인이나 반려로 요청을 끝내세요.
- 관리자 접근 선택칸에 마우스를 올리면 `자기 계정의 관리자 접근은 회수할 수 없습니다.`가 나옵니다. 내 계정은 다른 관리자가 회수해야 합니다.
- `프로필(이름·학번·학과) 완성 전에는 부여할 수 없습니다.`: 프로필 카드에서 빠진 값을 채운 뒤 다시 시도하세요.
- `활성 관리자 계정을 최소 한 개 유지해야 합니다.`: 다른 관리자를 먼저 지정하세요.
- `사용자 접근 상태가 조회 당시와 달라졌습니다.`: 다른 사람이 먼저 바꿨습니다. 화면을 새로 고쳐 현재 값을 보고 다시 하세요.
- `요청을 처리하지 못했습니다. 잠시 후 다시 시도해 주세요.`: 잠시 뒤 다시 시도하세요.
</Recover>
