`교직원` 역할은 가입만으로 쓸 수 없습니다. 관리자가 승인해야 프로그램을 만들고 신청을 판정할 수 있고, 승인 전에는 대기 화면만 보입니다.

로그인과 1단계(동의)는 학생과 같습니다. [가입하고 프로필 입력하기](/oss-hub/student/sign-up/)의 로그인과 1단계를 먼저 끝내세요.

## 교직원 역할 요청하기

<Steps>
1. 2단계 `어떤 역할로 쓰시나요`에서 ① `교직원` 카드를 고릅니다. 카드에 `관리자 승인이 필요합니다`라고 적혀 있습니다.
2. `선택 완료`를 누릅니다.
3. 3단계에서 `이름`을 입력하고 `소속 유형`(`학과` 또는 `사업단`)과 소속을 고릅니다. 교직원은 학번과 전화번호를 입력하지 않습니다.
4. `가입 마치기`를 누릅니다.
</Steps>
<Shot src="staff/role-staff-card.webp" alt="가입 2단계 화면. ①이 선택된 교직원 카드를 가리킵니다." caption="① `교직원` 카드" />

## 승인을 기다리기

가입을 마치면 `교직원 승인을 기다리고 있습니다` 화면과 `승인 대기` 표시가 나옵니다. 승인 결과는 메일이나 알림으로 오지 않습니다. 이 화면에서 직접 확인해야 합니다.

<Steps>
1. 관리자에게 승인을 부탁합니다. 관리자는 [교직원 권한 요청 처리하기](/oss-hub/admin/applicants/)에서 처리합니다.
2. 잠시 뒤 ① `상태 새로고침`을 눌러 승인되었는지 확인합니다.
3. 이름이나 소속을 잘못 적었다면 `이름·학과 고치기`를 누릅니다. 설정 화면이 열립니다.
</Steps>
<Shot src="staff/pending-waiting.webp" alt="교직원 승인 대기 화면. 승인 대기 표시가 있고 ①이 상태 새로고침 버튼을 가리킵니다. 아래에 이름·학과 고치기 버튼이 있습니다." caption="① 상태 새로고침" />

<Success>
승인이 반영되면 대기 화면이 사라지고 `운영 대시보드`가 열립니다.
</Success>

## 반려되었을 때

반려되면 역할 선택 화면이 다시 열리고 `교직원 요청이 반려되었습니다`와 반려 사유가 나옵니다. 사유를 읽고 고칠 것이 있으면 고친 뒤, ① `교직원`을 다시 고르고 `선택 완료`를 누르세요. 승인 요청이 새로 접수됩니다.

<Shot src="staff/role-rejected.webp" alt="역할 선택 화면. 위쪽에 교직원 요청이 반려되었다는 안내와 사유가 있고 ①이 교직원 카드를 가리킵니다." caption="① 다시 요청하려면 `교직원`을 고릅니다" />

<Recover title="막혔을 때">
- `접근 권한이 없습니다`: 교직원 권한이 없는 계정으로 운영 화면을 열었습니다. `내 화면으로 돌아가기`를 누르고, 승인 상태를 확인하세요.
- `로그인 요청을 완료하지 못했습니다. 다시 시도해 주세요.`: 로그인을 처음부터 다시 시도합니다.
- 승인이 한참 지나도 `승인 대기`입니다: 관리자에게 직접 요청이 도착했는지 확인해 달라고 하세요.
- 계정이 비활성화되어 있으면 관리자만 되살릴 수 있습니다. [계정 비활성화와 재활성화](/oss-hub/admin/deactivate/)를 참고하세요.
</Recover>
