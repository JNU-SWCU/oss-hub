프로그램 목록과 상세, `랭킹`은 로그인하지 않아도 볼 수 있습니다. 신청과 제출은 로그인한 `학생`만 합니다.

## 목록에서 고르기

<Steps>
1. 위쪽 `프로그램`을 누릅니다. 첫 화면의 `현재 모집 중인 프로그램`에서 바로 열 수도 있습니다.
2. 왼쪽에서 `전체`, `모집중`, `진행중`, `예정`, `종료` 중 보고 싶은 상태를 누릅니다. 각 숫자는 해당 프로그램 수입니다.
3. 이름을 찾으려면 `프로그램명 검색`에 입력합니다. `정렬 기준`은 `기본순`, `프로그램 이름`, `지원 기간`, `상태` 중에서 고릅니다.
4. 카드의 `자세히`를 눌러 상세로 들어갑니다.
</Steps>
<Shot src="intro/programs.webp" alt="프로그램 목록. 왼쪽에 상태별 개수가 있고 오른쪽에 검색칸, 정렬 기준, 프로그램 카드가 있습니다." caption="① 프로그램명 검색  ② 자세히" />

로그인하면 내가 신청한 프로그램 카드에 `신청` 또는 `반려` 배지가 붙습니다.

## 상세에서 확인하기

상세에서는 `프로그램 안내`, `신청 기간`, `운영 기간`, 제출 일정인 `마일스톤`을 봅니다. 아직 신청한 적이 없는 학생과 로그인 전 방문자에게는 `신청하기`가 보입니다. 로그인 전에 누르면 GitHub 로그인으로 이어집니다. 교직원과 관리자, 이미 신청한 학생에게는 버튼이 없습니다. [팀을 만들어 신청하기](/oss-hub/student/apply/)로 이어집니다.

<Shot src="intro/program-detail.webp" alt="로그인 전에 본 프로그램 상세 화면. 프로그램 소개와 일정이 있습니다." caption="프로그램 상세" />

<Success>
상세에 `모집중` 배지와 `신청하기` 버튼이 보이면 지금 신청할 수 있는 프로그램입니다. 신청 기간이 아니면 신청이 받아지지 않습니다.
</Success>

<Recover title="찾는 프로그램이 안 보일 때">
- `조건에 맞는 프로그램이 없습니다`: 검색어를 지우거나 `전체`를 누르세요. 필터를 한 번에 되돌리는 버튼은 없습니다.
- `종료된 프로그램이 없습니다`, `등록된 프로그램이 없습니다`: 아직 해당 프로그램이 없는 것입니다.
- `프로그램을 찾을 수 없습니다`: 삭제됐거나 공개되지 않은 프로그램입니다. `프로그램 목록으로`로 돌아가세요.
- `신청하기`가 비활성이고 `종료된 프로그램이라 신청을 받지 않습니다.`가 보이면 신청이 끝난 프로그램입니다.
- 학과 같은 추가 신청 자격 항목은 제품에 없고, 학과로 신청이 막히지도 않습니다. 신청이 반려되면 `우리 팀`에서 `반려 사유`를 보고 주관 교직원에게 문의하세요.
</Recover>
