팀 저장소는 두 경로로 생깁니다. 프로그램이 저장소를 발급하면 승인 때 자동으로 만들어집니다. 직접 만든 공개 저장소를 쓰는 팀은 `우리 팀`에서 주소를 등록합니다.

## 발급된 저장소 확인하기

<Steps>
1. 왼쪽 메뉴에서 `내 저장소`를 엽니다.
2. 저장소 카드의 상태를 확인합니다. `저장소 생성 중`이면 잠시 기다립니다.
3. `초대 수락 대기`이면 GitHub에서 받은 저장소 초대를 직접 수락합니다. OSS Hub는 대신 수락해 주지 않습니다.
4. `GitHub에서 열기`를 눌러 저장소에 들어갑니다.
</Steps>

저장소 생성과 초대 발송은 자동이고, 초대 수락만 직접 합니다.

## 직접 만든 저장소 등록하기

팀장만 할 수 있고, 신청이 승인된 뒤 프로그램이 끝나기 전까지만 가능합니다. 저장소는 GitHub에 공개되어 있어야 합니다.

<Steps>
1. 대시보드 카드의 `우리 팀`을 열고 `프로젝트 저장소`로 갑니다.
2. ① 연필 아이콘을 누릅니다.
3. `새 저장소 URL`에 GitHub 저장소 주소를 입력합니다.
4. 체크 아이콘으로 저장합니다. 취소는 X 아이콘입니다.
</Steps>
<Shot src="student/team-repo.webp" alt="프로젝트 저장소 영역. ①이 연필 아이콘을 가리킵니다." caption="① 수정 시작" />
<Shot src="student/team-repo-edit.webp" alt="새 저장소 URL 입력칸과 저장, 취소 아이콘." caption="주소 입력" />

<Success>
`저장소 변경을 저장했습니다.`가 나오고 활동 수집이 자동으로 시작됩니다. 수집된 활동은 [활동 보기](/oss-hub/student/activity/)에서 봅니다.
</Success>

<Recover title="등록이 안 될 때">
- `승인된 신청만 프로그램 종료 전에 저장소를 변경할 수 있습니다.`: 승인 전이거나 프로그램이 끝났습니다. 팀원은 변경할 수 없고 팀장만 가능합니다.
- `연결하려는 저장소를 찾을 수 없거나 비공개 저장소입니다. GitHub에 공개된 저장소만 연결할 수 있습니다.`: 주소 오타와 공개 여부를 확인하세요.
- `다른 신청에 연결된 저장소입니다.`: 다른 팀이 쓰는 저장소입니다.
- `저장소를 처리 중입니다…`: 잠시 뒤 다시 확인하세요.
- `GitHub 저장소를 확인할 수 없습니다…`: GitHub 쪽 문제일 수 있으니 시간을 두고 다시 시도하세요.
- 외부 저장소는 현재 동의 상태도 필요합니다. [가입 동의](/oss-hub/student/sign-up/)를 확인하세요.
- 남의 저장소를 등록할 때의 소유권 확인 기준은 화면에 나와 있지 않습니다. <Verified status="policy" />
</Recover>
